# 复习测验:看一眼 AI 做出的文件

- 课程:你的第一个网站(`first-website`)
- 课时:A first look at the files the AI made(`peek-at-the-files`)
- 题型:单选

## 第 1 题

三类文件里,哪一类主要管页面的结构,例如标题和段落?

- A. CSS
- B. HTML
- C. JavaScript
- D. images 文件夹

**答案:B**

解析:HTML 负责页面的结构,课文用标题和段落的例子说明了这一点。

依据:HTML: the structure of the page

## 第 2 题

想调整页面的颜色或字体大小,最应该先看哪一类文件?

- A. CSS 样式表
- B. HTML 标题
- C. 浏览器的历史记录
- D. 提交记录

**答案:A**

解析:CSS 负责页面的样式,颜色和字体大小这类外观设置通常写在样式表里。

依据:CSS: the style of the page

## 第 3 题

助手对某个文件的解释和你在页面上看到的内容对不上时,正确做法是什么?

- A. 直接接受这个解释
- B. 忽略这个文件
- C. 说明你看到的现象,然后再问一次
- D. 删除这个文件

**答案:C**

解析:课文要求解释必须和页面实际表现对得上,对不上时要说明现象并再问。

依据:Ask the AI to explain a file and check it yourself
