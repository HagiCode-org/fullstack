# 复习测验:得到第一版

- 课程:你的第一个网站(`first-website`)
- 课时:Get the first version(`first-version`)
- 题型:单选

## 第 1 题

得到第一版后,你要记录什么?

- A. 助手的名字
- B. 电脑的型号
- C. 按重要性排序的问题清单
- D. 一个空文件

**答案:C**

解析:自检标准:写下问题清单,最重要的放在前面。

## 第 2 题

第一版完成后,提交应该叫什么才符合课程要求?

- A. `asdf`
- B. `First version`
- C. `final final`
- D. 什么都不写

**答案:B**

解析:自检标准:GitHub Desktop 历史里有名为 `First version` 的提交。

## 第 3 题

网站打不开时,应该怎么办?

- A. 按课程“网站打不开”部分排查
- B. 立刻重装系统
- C. 删除文件夹
- D. 换一个网站

**答案:A**

解析:本课包含“如果网站打不开”的排查小节。
