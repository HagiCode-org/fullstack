# 复习测验:得到第一版

- 课程:你的第一个网站(`first-website`)
- 课时:Get the first version(`first-version`)
- 题型:单选

## 第 1 题

得到第一版后,课文要求你先做什么?

- A. 立即要求助手全部修复
- B. 打开网站并列出问题清单,最重要的放在最前面
- C. 删除助手生成的所有文件
- D. 重新写一份完全不同的需求

**答案:B**

解析:课文要求先逐项检查网站,写下问题清单并把最重要的放在前面,暂时不要求修复。

依据:What you will do

## 第 2 题

网站打不开时,课文建议怎样处理?

- A. 复制原样的报错文字和操作步骤交给助手,失败三次后停下
- B. 立即重装电脑系统
- C. 删除整个文件夹
- D. 把报错截图删掉

**答案:A**

解析:“If the site does not open”一节要求原样复制报错,并在三次失败后停下。

依据:If the site does not open

## 第 3 题

为什么说第一版不等于最终网站?

- A. 因为第一版一定打不开
- B. 因为助手可能猜了一些细节,问题清单会指导下一步修改
- C. 因为提交记录不能包含第一版
- D. 因为浏览器只能显示一个页面

**答案:B**

解析:课文说明第一版只是起点,助手可能猜测了你没有写下的细节,问题清单决定下一步修改什么。

依据:Why the first version is not the finished site
