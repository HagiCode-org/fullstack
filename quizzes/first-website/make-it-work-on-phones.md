# 复习测验:适配手机

- 课程:你的第一个网站(`first-website`)
- 课时:Make it work on phones(`make-it-work-on-phones`)
- 题型:单选

## 第 1 题

“响应式”页面指什么?

- A. 回复很快的页面
- B. 只能在手机上看的页面
- C. 只能在电脑上看的页面
- D. 会根据屏幕宽度调整布局的页面

**答案:D**

解析:响应式就是布局随屏幕宽度调整。

## 第 2 题

在窄屏上应当检查什么?

- A. 文字不被截断,页面不会横向滚动
- B. 页面的字体越小越好
- C. 图片越大越好
- D. 不用检查

**答案:A**

解析:自检标准:窄屏下文字不被截断,页面不横向滚动。

## 第 3 题

链接和按钮在手机上需要满足什么?

- A. 越小越好
- B. 大小足够容易点按
- C. 隐藏起来
- D. 必须是红色

**答案:B**

解析:自检标准:链接和按钮要足够大,能按得到。
