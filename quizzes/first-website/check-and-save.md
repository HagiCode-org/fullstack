# 复习测验:验收并存档

- 课程:你的第一个网站(`first-website`)
- 课时:Check the site and save it(`check-and-save`)
- 题型:单选

## 第 1 题

验收网站时,哪一种做法最符合课文要求?

- A. 相信助手说已经完成了
- B. 只勾选你亲眼看到的条目
- C. 不检查链接是否可用
- D. 把验收清单删除

**答案:B**

解析:课文强调只有亲眼看到的条目才能打勾,清单的意义就在于逐条检查。

依据:Why a checklist and not a feeling

## 第 2 题

发现网站里有私人信息时,应该怎样处理?

- A. 保留下来并发布
- B. 把它写进网站的标题里
- C. 提交之前删除,并询问助手如何处理已经提交过的历史记录
- D. 直接发给陌生人看

**答案:C**

解析:“About private information”一节说明,即使后来删除,早先的提交仍然可以找到,所以要询问助手如何处理。

依据:About private information

## 第 3 题

在 GitHub Desktop 的改动文件列表里取消勾选某个文件,会有什么结果?

- A. 该文件会被删除
- B. 该文件不会进入这一次提交
- C. 整个提交会被取消
- D. 网站会被立即发布

**答案:B**

解析:GitHub 的文档说明,取消勾选某个文件的复选框,这个文件就不会被加入提交。

依据:What you will do
