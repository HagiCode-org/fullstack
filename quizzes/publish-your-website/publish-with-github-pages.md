# 复习测验:用 GitHub Pages 发布

- 课程:发布你的网站(`publish-your-website`)
- 课时:Publish with GitHub Pages(`publish-with-github-pages`)
- 题型:单选

## 第 1 题

GitHub Pages 发布后,地址大致是什么样?

- A. `localhost:8080`
- B. `file:///`
- C. `ftp://`
- D. `your-name.github.io`

**答案:D**

解析:课程说明地址形如 `your-name.github.io`。

## 第 2 题

怎样验证网站真的发布成功了?

- A. 在另一台设备上打开这个 `github.io` 地址
- B. 只在自己电脑上打开本地文件
- C. 看仓库图标
- D. 重启电脑

**答案:A**

解析:自检标准:能在另一台设备上打开。

## 第 3 题

发布之前应该检查仓库里什么?

- A. 有没有大图片
- B. 没有任何私人内容
- C. 有几个分支
- D. 有没有表情符号

**答案:B**

解析:自检标准:确认仓库里没有私密内容。
