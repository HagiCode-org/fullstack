# 复习测验:一个网页是怎样被打开的

- 课程:发布你的网站(`publish-your-website`)
- 课时:How a web page gets to your screen(`how-a-page-opens`)
- 题型:单选

## 第 1 题

在 `https://example.com/about` 中,`example.com` 指的是什么?

- A. 页面的文件大小
- B. 域名,也就是用来找到服务器的主机名
- C. 请求的路径
- D. 浏览器的版本

**答案:B**

解析:这一段是主机名,也就是域名,它用来找到负责这个网站的计算机。

依据:The address

## 第 2 题

浏览器发给服务器、请求文件的消息叫什么,服务器回复的消息又叫什么?

- A. 请求是 request,回复是 response
- B. 请求是 domain,回复是 path
- C. 请求是 cache,回复是 log
- D. 请求是 CDN,回复是 DNS

**答案:A**

解析:请求由浏览器发出,服务器返回的回复称为响应,两者合称请求与响应。

依据:What the browser asks for

## 第 3 题

为什么只存在于你电脑上的网站,朋友的浏览器打不开?

- A. 因为他们的浏览器太旧
- B. 因为网址一定写错了
- C. 因为你的电脑不是一台一直在线、别人能访问到的服务器
- D. 因为网页文件太小

**答案:C**

解析:要让别人访问,网站必须放在总在线、别人能够到达的服务器上。

依据:Why this matters for publishing
