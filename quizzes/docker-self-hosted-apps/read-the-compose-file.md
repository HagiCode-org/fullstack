# 复习测验:让 AI 帮你读懂应用的 compose 文件

- 课程:用 Docker 部署现成应用(`docker-self-hosted-apps`)
- 课时:Understand an app’s compose file with AI(`read-the-compose-file`)
- 题型:单选

## 第 1 题

应用自带的 compose 文件主要告诉你什么?

- A. 作者的联系方式
- B. 它需要哪些容器,以及它们如何连接
- C. 电脑的型号
- D. 应用的价格

**答案:B**

解析:compose 文件列出应用需要的容器和连接方式。

## 第 2 题

课程要求你从 compose 文件里找出哪四类信息?

- A. 颜色、字体、图标、动画
- B. 作者、日期、版本、许可证
- C. 端口、数据存放位置、密码、如何备份
- D. 内存、显卡、硬盘、屏幕

**答案:C**

解析:四个问题是:端口、数据在哪里、密码、怎么备份。

## 第 3 题

让 AI 解释 compose 文件后,你还应该怎么做?

- A. 直接照做,不必核对
- B. 把文件发给陌生人
- C. 删掉文件
- D. 自己在文件里核对每个答案,不要只信 AI

**答案:D**

解析:自检标准要求每个答案都在文件里找到,而不是只依赖 AI。
