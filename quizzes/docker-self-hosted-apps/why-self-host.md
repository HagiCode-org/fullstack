# 复习测验:为什么要自己运行应用

- 课程:用 Docker 部署现成应用(`docker-self-hosted-apps`)
- 课时:Why run apps yourself(`why-self-host`)
- 题型:单选

## 第 1 题

“自托管”指什么?

- A. 把程序上传到应用商店
- B. 在自己的电脑或服务器上运行程序,而不是使用别人托管的网站服务
- C. 只在手机上使用应用
- D. 购买付费会员

**答案:B**

解析:自托管就是自己运行程序。

## 第 2 题

下面哪一项是自托管需要承担的代价?

- A. 不需要任何电脑
- B. 数据一定会丢失
- C. 需要自己负责更新、备份和安全
- D. 完全不需要学习

**答案:C**

解析:自托管的好处是掌控,代价是要自己维护。

## 第 3 题

做完这一课,你应当能写出什么?

- A. 一个完整的操作系统
- B. 一份法律合同
- C. 一个新的编程语言
- D. 一份一到三个应用的候选清单,并说明先试哪一个

**答案:D**

解析:自检标准要求写出一到三个候选应用的清单。
