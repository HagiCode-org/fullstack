# 复习测验:备份、升级与恢复

- 课程:用 Docker 部署现成应用(`docker-self-hosted-apps`)
- 课时:Back up, upgrade and restore(`back-up-upgrade-restore`)
- 题型:单选

## 第 1 题

备份文件应该放在哪里才安全?

- A. 放在 Docker 之外
- B. 只放在同一个容器里
- C. 不用保存
- D. 放在公开网站上

**答案:A**

解析:备份要存放在 Docker 之外,容器没了它仍在。

## 第 2 题

为什么要在测试副本里恢复一次备份?

- A. 为了让应用变快
- B. 为了删除旧数据
- C. 为了换一种语言
- D. 确认备份真的能用

**答案:D**

解析:只有恢复过才能确认备份有效。

## 第 3 题

升级应用前,你至少应该知道什么?

- A. 电脑的 IP 地址
- B. 作者的生日
- C. 当前运行的版本,以及到哪里修改版本
- D. 显示器的尺寸

**答案:C**

解析:自检标准要求知道当前版本和修改位置,以便出错时退回。
