# 复习测验:与第一个版本对比

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Compare with the first version(`compare-with-the-first-version`)
- 题型:单选

## 第 1 题

比较两个版本时,应该怎样测试?

- A. 各用不同的输入
- B. 只测一个版本
- C. 不测试
- D. 用同样的三个输入分别测试

**答案:D**

解析:自检标准:两个版本用同样的三个输入测试。

## 第 2 题

本课教的判断力是什么?

- A. 不逐行读代码也能判断结果好不好
- B. 把代码背下来
- C. 把代码打印出来
- D. 只看代码行数

**答案:A**

解析:课程原话。

## 第 3 题

你应该写下什么?

- A. 代码的行数
- B. 哪些事不读代码也能判断,哪些不能
- C. 作者的名字
- D. 电脑的型号

**答案:B**

解析:自检标准:写下不读代码能判断与不能判断的部分。
