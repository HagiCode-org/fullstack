# 复习测验:与第一个版本对比

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Compare with the first version(`compare-with-the-first-version`)
- 题型:单选

## 第 1 题

什么是测试用例(test case)?

- A. 一个完整的软件
- B. 一份固定的输入,加上你期望得到的结果
- C. 一个 Python 包
- D. 一段错误信息

**答案:B**

解析:测试用例把输入和期望结果固定下来,两个版本才能用同一个标准来比较。

依据:The method

## 第 2 题

比较两个版本时,为什么要使用相同的输入?

- A. 为了让两个版本看起来一样
- B. 为了节省测试时间
- C. 为了删除旧版本
- D. 为了让比较公平,结果才能对照

**答案:D**

解析:只有输入相同,结果的不同才能说明版本之间的差异。

依据:What you will do

## 第 3 题

下面哪一件事无法只靠运行程序来判断?

- A. 页面能否打开
- B. 同一输入的结果是否一致
- C. 代码结构是否清楚、是否容易修改
- D. 出错时是否显示信息

**答案:C**

解析:代码是否清楚需要读代码或更深入的检查,单靠运行程序看不出来。

依据:What you cannot judge without reading code
