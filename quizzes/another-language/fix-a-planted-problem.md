# 复习测验:修复一个预设的问题

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Fix a planted problem(`fix-a-planted-problem`)
- 题型:单选

## 第 1 题

官方教程建议阅读 Python 报错时先看哪一行?

- A. 第一行
- B. 中间的一行
- C. 最后一行,它说明发生了什么
- D. 文件名所在的那一行

**答案:C**

解析:官方教程说明,错误信息的最后一行指出发生了什么。

依据:Read a Python error

## 第 2 题

`ModuleNotFoundError` 的意思是什么?

- A. 无法找到要导入的模块
- B. 文件已经被删除
- C. 网络已经断开
- D. 键盘输入有误

**答案:A**

解析:官方参考说明,导入模块时找不到该模块就会引发 ModuleNotFoundError。

依据:Read a Python error

## 第 3 题

向 AI 求助时应当提供什么?

- A. 只说“不能用了”
- B. 原样的错误文字、你正在执行的步骤,以及你期望的结果
- C. 另一个项目的全部文件
- D. 你的电脑型号

**答案:B**

解析:准确的错误文字和步骤能让 AI 找到原因,不要凭记忆改写错误信息。

依据:What you will do
