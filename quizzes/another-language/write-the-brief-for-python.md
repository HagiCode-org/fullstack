# 复习测验:为 Python 版本写需求说明

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Write the brief for a Python version(`write-the-brief-for-python`)
- 题型:单选

## 第 1 题

为 Python 版本写需求说明时,哪一项应当保持不变?

- A. 编程语言
- B. 应用要完成的工作
- C. 所用的框架
- D. 运行的操作系统

**答案:B**

解析:工作本身不变;变化的是语言,以及新增的语言说明、规则和操作系统说明。

依据:What changes and what does not

## 第 2 题

需求里的“规则”部分应当写什么?

- A. 让 AI 自行安装任何需要的软件
- B. 一次修改所有文件,节省时间
- C. 在执行有风险的操作前先询问你
- D. 把真实密钥写进代码,方便运行

**答案:C**

解析:规则要求 AI 在安装软件、删除文件或使用管理员权限之前先询问你。

依据:What you will do

## 第 3 题

为什么要在需求里写明你使用 Windows 还是 macOS?

- A. 让 AI 给出适合你系统的命令
- B. 为了改变费用
- C. 为了让程序运行得更快
- D. 为了删除旧文件

**答案:A**

解析:Windows 和 macOS 的命令不同,如果需求里不说明,AI 只能猜测。

依据:What changes and what does not
