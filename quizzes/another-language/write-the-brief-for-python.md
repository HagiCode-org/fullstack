# 复习测验:为 Python 版本写需求说明

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Write the brief for a Python version(`write-the-brief-for-python`)
- 题型:单选

## 第 1 题

好的需求描述的是什么?

- A. 语言,而不是任务
- B. 作者的名字
- C. 任务,而不是语言
- D. 电脑的配置

**答案:C**

解析:课程原话:好的需求描述的是任务。

## 第 2 题

需求里应该让 AI 在什么时候先问你?

- A. 从来不用问
- B. 要执行有风险的操作之前
- C. 只在结束时
- D. 只在开始时

**答案:B**

解析:自检标准:要求 AI 在风险操作之前先问。

## 第 3 题

完成清单应该放在哪里?

- A. 作为需求的一部分
- B. 另外放在别人那里
- C. 不需要
- D. 只在脑子里

**答案:A**

解析:自检标准:完成清单是需求的一部分。
