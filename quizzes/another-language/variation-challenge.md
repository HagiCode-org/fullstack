# 复习测验:挑战:用第三种语言完成同一件事

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Challenge: the same job in a third language(`variation-challenge`)
- 题型:单选

## 第 1 题

根据 Node.js 官方网站,Node.js 是什么?

- A. 一个图片编辑器
- B. 一种异步、事件驱动的 JavaScript 运行环境
- C. 一个操作系统
- D. 一种数据库

**答案:B**

解析:官方网站把 Node.js 描述为 JavaScript 运行环境,它负责运行用 JavaScript 写的程序。

依据:Choose a third language

## 第 2 题

安装第三个版本需要的工具时,应当怎样做?

- A. 从任何搜索结果中下载
- B. 让朋友发给你安装包
- C. 关闭杀毒软件后再安装
- D. 检查下载地址属于该工具自己的官方网站

**答案:D**

解析:课程要求只从工具自己的官方网站获取安装包,并在安装前确认下载地址。

依据:What you will do

## 第 3 题

第三个版本应当与前两个版本怎样比较?

- A. 只比较代码行数
- B. 使用同样的检查清单和同样的输入
- C. 比较作者的名字
- D. 比较安装目录

**答案:B**

解析:同样的检查清单和输入,才能说明第三个版本是否达到了同样的要求。

依据:Judge it without reading it
