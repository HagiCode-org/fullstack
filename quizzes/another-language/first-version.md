# 复习测验:运行第一个版本

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Get the first version running(`first-version`)
- 题型:单选

## 第 1 题

虚拟环境(virtual environment)的作用是什么?

- A. 让程序运行得更快
- B. 把本项目的包放在项目自己的文件夹里,与其他项目分开
- C. 替代 AI 助手
- D. 保存网页浏览历史

**答案:B**

解析:虚拟环境是项目自己的文件夹,里面的包不会与电脑上其他项目的包混在一起。

依据:Windows

## 第 2 题

在 Mac 上,激活虚拟环境应当运行哪一条命令?

- A. `.venv\Scripts\activate`
- B. `source .venv/bin/activate`
- C. `python -m pip freeze`
- D. `fastapi dev main.py`

**答案:B**

解析:Mac 使用 `source` 命令运行 `.venv/bin` 目录里的激活脚本;Windows 使用 `Scripts` 目录。

依据:Mac

## 第 3 题

AI 要求以管理员权限安装东西时,你应该怎么做?

- A. 立即同意,以免耽误进度
- B. 关闭终端并删除项目
- C. 忽略提示,继续运行
- D. 停下来,让它解释为什么需要这样做

**答案:D**

解析:课程要求遇到管理员权限或看不懂的命令时先停下来询问,而不是直接同意。

依据:Safety note
