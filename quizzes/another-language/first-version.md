# 复习测验:运行第一个版本

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:Get the first version running(`first-version`)
- 题型:单选

## 第 1 题

做应用时,AI 可能会使用什么?

- A. 计算器
- B. 画图板
- C. 框架,例如 FastAPI
- D. 电子表格

**答案:C**

解析:框架是搭建 Web 应用的现成工具集。

## 第 2 题

程序应该怎样运行起来?

- A. 随便猜命令
- B. 按 AI 给出的步骤运行
- C. 不运行
- D. 等一年

**答案:B**

解析:自检标准:按 AI 给的步骤运行。

## 第 3 题

第一版跑通之后应该做什么?

- A. 保存一个存档点
- B. 删除历史
- C. 换电脑
- D. 关闭项目

**答案:A**

解析:自检标准:保存可用版本的存档点。
