# 复习测验:看看目标

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:See the goal(`see-the-goal`)
- 题型:单选

## 第 1 题

这一课要求你怎样描述任务?

- A. 必须写出具体代码
- B. 只写语言名称
- C. 不提任何编程语言,只描述要完成的工作
- D. 不用描述

**答案:C**

解析:自检标准:能不提语言地描述任务。

## 第 2 题

为什么要准备一个简短的检查方法?

- A. 为了让代码变短
- B. 用来判断任务是否完成
- C. 为了换语言
- D. 为了删文件

**答案:B**

解析:自检标准:要有简短的方法检查任务完成。

## 第 3 题

课程里这一次让 AI 用哪种语言完成任务?

- A. Python
- B. COBOL
- C. 汇编
- D. 没有指定

**答案:A**

解析:课程原话:让它用 Python 完成。
