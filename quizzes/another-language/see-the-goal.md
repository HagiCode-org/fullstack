# 复习测验:看看目标

- 课程:用另一种语言做同一个应用(`another-language`)
- 课时:See the goal(`see-the-goal`)
- 题型:单选

## 第 1 题

这一课为什么要先写工作描述,而且不提任何编程语言?

- A. 因为必须先学会 Python
- B. 因为语言已经定好,不能再改
- C. 因为好的描述不随语言改变,先写可以分清你的要求与 AI 的决定
- D. 因为描述越长越好

**答案:C**

解析:好的描述不随语言改变,先写下来,之后才能看清哪些是你的要求、哪些是 AI 的决定。

依据:Why the description comes first

## 第 2 题

判断任务是否完成,应当使用什么?

- A. 只看 AI 说“完成了”
- B. 使用你在工作描述里写下的简短检查方法
- C. 完全不检查
- D. 删除旧版本

**答案:B**

解析:自检标准要求你有一个简短的方法来判断任务是否完成,这个方法就写在工作描述里。

依据:What you will do

## 第 3 题

这一课让你在哪两个选项之间选择?

- A. 重做同一个小应用,或写一个小脚本
- B. 安装 Python,或安装 Docker
- C. 学习两门新的编程语言
- D. 只完成复习测验

**答案:A**

解析:课程给出两个选项:重做《你的第一个 Web 应用》里的小应用,或写一个做重复工作的小脚本。

依据:What you will do
