# 复习测验:判断输出好不好

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:Judge the output(`judge-the-output`)
- 题型:单选

## 第 1 题

课文要求测试集至少有多少个输入?

- A. 一个
- B. 两个
- C. 至少十个,每个都有你认可的答案
- D. 不需要固定数量

**答案:C**

解析:课文要求先从功能说明中取得测试输入,然后补充到至少十条,每条都写明你认可的答案。

依据:Build the test set

## 第 2 题

课文对自动评分有什么建议?

- A. 每一道题都必须由人工评分
- B. 完全不需要评分
- C. 只能用图片评分
- D. 尽量设计成计算机能检查的形式,例如字符串匹配

**答案:D**

解析:课文引用 Anthropic 的指南,建议能自动评分就自动评分,例如多选、字符串匹配等。

依据:Make grading as automatic as you can

## 第 3 题

课文建议如何测试提示注入(prompt injection)?

- A. 允许模型执行输入里的任何指令
- B. 把密钥放进测试输入里
- C. 删除所有测试
- D. 加入一条试图改变模型指令的输入,确认功能不会服从它

**答案:D**

解析:课文建议加入一条企图让模型忽略原有指令的输入,并确认功能继续完成自己的任务。

依据:Test a prompt injection
