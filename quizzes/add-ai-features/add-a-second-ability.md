# 复习测验:再加第二个能力

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:Add a second ability(`add-a-second-ability`)
- 题型:单选

## 第 1 题

为什么加入第二个能力之后,还要重新检查第一个能力?

- A. 每次修改都可能破坏原来认可的答案
- B. 第一个能力不需要测试
- C. 模型会自动更新旧答案
- D. 必须删除旧的测试

**答案:A**

解析:回归测试的意义是确认你之前认可的答案在改动之后仍然成立。

依据:Why the first ability must be checked again

## 第 2 题

课文对同一输入多次运行有什么建议?

- A. 运行一次就足够
- B. 多次运行并比较输出,输出不一致可能提示幻觉
- C. 删除结果不一致的测试
- D. 只能用图片来测试

**答案:B**

解析:课文引用 Anthropic 的指南:同一提示词多次运行并比较输出,输出不一致可能说明存在幻觉。

依据:Run the same test twice

## 第 3 题

课文建议如何添加第二个能力?

- A. 一次重写整个应用
- B. 删除第一个能力
- C. 小步修改,并保持第一个能力不变
- D. 把密钥直接写进代码

**答案:C**

解析:课文要求只做小的改动,并明确告诉助手不要改变第一个能力的工作方式。

依据:What you will do
