# 复习测验:先看做好的功能

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:See the finished feature(`see-the-finished-feature`)
- 题型:单选

## 第 1 题

“AI 功能”指什么?

- A. 应用的启动画面
- B. 应用的图标
- C. 应用中由模型读取文字并写出有用回答的部分
- D. 应用的名字

**答案:C**

解析:课程定义:模型读文字、写回答。

## 第 2 题

你应该能用一句话说出什么?

- A. 模型的价格
- B. 你要做的功能,例如“把每条笔记总结成两行”
- C. 模型的大小
- D. 作者的名字

**答案:B**

解析:自检标准:能用一句话说出功能。

## 第 3 题

做完示例之后,你应该写下什么?

- A. 至少一个好的回答和一个不好的回答
- B. 只写好的
- C. 什么都不写
- D. 只写价格

**答案:A**

解析:自检标准:记录至少一好一差的回答。
