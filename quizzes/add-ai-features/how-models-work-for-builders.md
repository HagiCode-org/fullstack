# 复习测验:做应用的人需要了解的模型常识

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:What builders need to know about models(`how-models-work-for-builders`)
- 题型:单选

## 第 1 题

Prompt 是什么?

- A. 模型的名字
- B. 模型的价格
- C. 模型的版本
- D. 发送给模型的文字,包含你的指令和要处理的材料

**答案:D**

解析:更清楚的 prompt 通常带来更好的回答。

## 第 2 题

多数服务按什么计费?

- A. 按发送和接收的 token 数量
- B. 按你的年龄
- C. 按你的屏幕大小
- D. 按你的位置

**答案:A**

解析:长文本比短文本花费更多。

## 第 3 题

模型可能出现什么情况?

- A. 永远正确
- B. 听起来很肯定却是错的
- C. 从不出错
- D. 不会编造

**答案:B**

解析:这是正常行为,不是罕见意外。
