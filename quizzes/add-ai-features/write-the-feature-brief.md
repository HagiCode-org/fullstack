# 复习测验:写功能说明

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:Write the feature brief(`write-the-feature-brief`)
- 题型:单选

## 第 1 题

功能说明(feature brief)是什么?

- A. 对功能必须做什么、绝不能做什么的简短书面描述
- B. 模型的评分
- C. 服务的价格表
- D. 一段广告

**答案:A**

解析:助手据此构建,你据此验收。

## 第 2 题

功能说明里至少要有几条“绝不能做”的事?

- A. 一条
- B. 零条
- C. 随便
- D. 至少三条

**答案:D**

解析:自检标准:至少列出三件功能绝不能做的事。

## 第 3 题

出现故障时,功能说明里应该写什么?

- A. 开发者的名字
- B. 服务的价格
- C. 用户会看到什么
- D. 什么都不写

**答案:C**

解析:自检标准:写明出故障时用户看到什么。
