# 复习测验:让第一版跑起来

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:Get the first version working(`first-version`)
- 题型:单选

## 第 1 题

API 是什么?

- A. 一个程序向另一个程序请求东西的方式
- B. 一种浏览器
- C. 一个图标
- D. 一个硬盘

**答案:A**

解析:你的应用通过模型服务的 API 发送 prompt 并接收回答。

## 第 2 题

API 密钥应该放在哪里?

- A. 写进网页
- B. 写进公开仓库
- C. 发在聊天群
- D. 项目文件之外的地方,不写进项目文件

**答案:D**

解析:自检标准:密钥不写在任何你看得到的项目文件里。

## 第 3 题

想知道当前的价格和可选模型,应该怎么做?

- A. 让助手凭记忆回答
- B. 去问朋友
- C. 去服务官方页面查看,而不是凭记忆问助手
- D. 随便猜

**答案:C**

解析:课程要求看服务自己的页面。
