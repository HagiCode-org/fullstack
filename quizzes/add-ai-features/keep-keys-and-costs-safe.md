# 复习测验:保管好密钥，控制好费用

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:Keep keys and costs safe(`keep-keys-and-costs-safe`)
- 题型:单选

## 第 1 题

API 密钥像什么?

- A. 银行卡号:拿到的人可以用你的账号并产生费用
- B. 一个公开的网址
- C. 一个昵称
- D. 一张壁纸

**答案:A**

解析:课程原话。

## 第 2 题

如何给费用设上限?

- A. 什么都不用做
- B. 相信不会超
- C. 多注册几个账号
- D. 在服务那里设置消费上限和提醒

**答案:D**

解析:自检标准:设置了消费上限和提醒。

## 第 3 题

面对一个超长文本,功能应该怎样?

- A. 直接全部发送
- B. 自动忽略错误
- C. 拒绝它,而不是发送出去
- D. 重启服务

**答案:C**

解析:自检标准:功能拒绝过长的文本。
