# 复习测验:挑战:给之前的应用加一个 AI 功能

- 课程:给应用加上 AI 功能(`add-ai-features`)
- 课时:Challenge: add an AI feature to an earlier app(`variation-challenge`)
- 题型:单选

## 第 1 题

这次挑战与第一次课程的主要区别是什么?

- A. 仍然使用同一个应用
- B. 不需要任何功能
- C. 使用不同的应用和不同的功能,并且不再给出示例
- D. 只看别人的成果

**答案:C**

解析:课文说明这次没有示例,你要用另一个应用和另一种功能,独立完成整门课的步骤。

依据:Choose your app and your feature

## 第 2 题

功能说明和测试清单应该在什么时候写好?

- A. 在功能构建之后
- B. 在功能构建之前
- C. 不需要写
- D. 在发布之后

**答案:B**

解析:课文要求先写说明书和至少十条测试输入,再让助手构建,这样功能不会只按它碰巧的回答来判断。

依据:Write before you build

## 第 3 题

挑战结束后,下一门课程的第一课是什么?

- A. Judge the output
- B. Get the first version working
- C. Keep keys and costs safe
- D. Work on a branch

**答案:D**

解析:课程页面写明,下一门课程是 GitHub 课程,它的第一课是 Work on a branch。

依据:Where to learn next
