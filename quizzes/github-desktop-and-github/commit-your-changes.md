# 复习测验:保存一个存档点（提交）

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Save a checkpoint (commit)(`commit-your-changes`)
- 题型:单选

## 第 1 题

“提交”(commit)是什么?

- A. 删除所有文件
- B. 把文件发给别人
- C. 为项目某一时刻的完整状态保存的、带说明的存档点
- D. 关闭程序

**答案:C**

解析:提交是带说明的快照。

## 第 2 题

提交说明应该怎么写?

- A. 写“aaa”
- B. 简短而清楚地说明改了什么
- C. 留空
- D. 写一长篇无关的话

**答案:B**

解析:清楚的说明让以后的你和他人看得懂历史。

## 第 3 题

推送(push)之后,提交会出现在哪里?

- A. GitHub 网站上
- B. 只在电脑的回收站里
- C. 浏览器的缓存里
- D. 不会出现

**答案:A**

解析:推送会把提交上传到 GitHub。
