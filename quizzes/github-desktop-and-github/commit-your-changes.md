# 复习测验:保存一个存档点（提交）

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Save a checkpoint (commit)(`commit-your-changes`)
- 题型:单选

## 第 1 题

在 GitHub Desktop 的 Changes 列表中,绿色图标表示什么?

- A. 修改过的文件
- B. 被删除的文件
- C. 新增的文件
- D. 发生冲突的文件

**答案:C**

解析:官方说明红色表示删除的文件,黄色表示修改的文件,绿色表示新增的文件。
依据:Edit a file and read the changes

## 第 2 题

“Summary”(提交说明)应该怎么写?

- A. 简短而清楚地说明这次改动做了什么
- B. 留空,什么都不写
- C. 写 “aaa” 这样没有意义的字符
- D. 写一篇与改动无关的长文

**答案:A**

解析:清楚的说明让你和别人以后都能看懂历史,这是提交说明的基本要求。
依据:Write a message and commit

## 第 3 题

放弃(Discard Changes)未提交的改动后,被放弃的内容会去哪里?

- A. 永久消失,无法恢复
- B. 保存在废纸篓中的带日期文件里,直到废纸篓被清空
- C. 自动推送到 GitHub 上
- D. 变成一条新的提交

**答案:B**

解析:官方说明被放弃的改动会保存在废纸篓的带日期文件中,在清空之前仍可以恢复。
依据:Discard a change you do not want
