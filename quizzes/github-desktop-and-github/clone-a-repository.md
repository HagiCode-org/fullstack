# 复习测验:克隆一个仓库

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Clone a repository(`clone-a-repository`)
- 题型:单选

## 第 1 题

“克隆”仓库指的是什么?

- A. 删除项目
- B. 给项目换个名字
- C. 把项目变成图片
- D. 把项目复制一份到自己的电脑上

**答案:D**

解析:克隆就是在本机得到一份项目副本。

## 第 2 题

克隆完成后,练习仓库应该存在于哪里?

- A. GitHub 上和你的电脑上
- B. 只在 GitHub 上
- C. 只在手机上
- D. 都不存在

**答案:A**

解析:自检标准:仓库在 GitHub 和本机都存在。

## 第 3 题

怎样确认克隆成功?

- A. 看电脑壁纸
- B. 在文件管理器里能找到 README,GitHub Desktop 显示该仓库为当前仓库
- C. 重启电脑
- D. 看浏览器历史

**答案:B**

解析:这两点是课程的自检标准。
