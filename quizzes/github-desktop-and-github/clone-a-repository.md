# 复习测验:克隆一个仓库

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Clone a repository(`clone-a-repository`)
- 题型:单选

## 第 1 题

在 GitHub Desktop 中,“克隆”(clone)一个仓库是什么意思?

- A. 在电脑上制作一份包括历史在内的完整副本
- B. 删除 GitHub 上的仓库
- C. 把仓库的名字改成另一个名字
- D. 把电脑上的改动立即发布到 GitHub

**答案:A**

解析:克隆会把仓库的文件和完整历史复制到电脑上,形成一个可以工作的本地副本。
依据:Clone it with GitHub Desktop

## 第 2 题

创建练习仓库时,哪个设置可以让只有你能看到这个仓库?

- A. Owner(所有者)
- B. Public(公开)
- C. Private(私有)
- D. README(说明文件)

**答案:C**

解析:仓库的可见性可以选择 Public 或 Private,练习仓库选择 Private 时只有你能看到它。
依据:Create a practice repository on GitHub

## 第 3 题

克隆完成后,你在电脑上做的改动为什么还没有出现在 GitHub 上?

- A. 因为克隆会删除 GitHub 上的文件
- B. 因为还没有推送(push),改动只留在你的电脑上
- C. 因为 GitHub 不接受来自电脑的改动
- D. 因为私有仓库不能在电脑上打开

**答案:B**

解析:电脑上的改动只有在推送之后才会发送到 GitHub,这是本地副本与远程仓库的区别。
依据:Check the copy on your computer
