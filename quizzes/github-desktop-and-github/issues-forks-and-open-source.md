# 复习测验:Issue、Fork 与开源

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Issues, forks and open source(`issues-forks-and-open-source`)
- 题型:单选

## 第 1 题

“开源”软件指什么?

- A. 免费的游戏
- B. 只有作者能看到的软件
- C. 任何人都可以阅读、使用和修改的软件
- D. 已经停止维护的软件

**答案:C**

解析:课程的定义:任何人都可以读、用和改。

## 第 2 题

Fork 是什么?

- A. 删除别人的项目
- B. 把别人的项目复制到自己的账号下,以便在自己的副本上修改
- C. 给项目点赞
- D. 给项目改名

**答案:B**

解析:Fork 是你账号下的一份副本。

## 第 3 题

一个好的 Issue 应该怎样?

- A. 清楚地描述问题
- B. 只写“不行”
- C. 一个字都不写
- D. 只贴表情

**答案:A**

解析:自检标准要求写出一个清楚的 Issue。
