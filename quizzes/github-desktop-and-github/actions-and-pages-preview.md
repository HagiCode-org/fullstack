# 复习测验:初识 Actions 与 Pages

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:A first look at Actions and Pages(`actions-and-pages-preview`)
- 题型:单选

## 第 1 题

GitHub Actions 做什么?

- A. 给照片加滤镜
- B. 压缩电脑文件
- C. 在仓库发生某些事时(例如推送)自动运行任务
- D. 修改你的密码

**答案:C**

解析:Actions 按事件自动运行任务。

## 第 2 题

GitHub Pages 做什么?

- A. 备份你的手机
- B. 把仓库里的文件作为网站展示出来
- C. 发送电子邮件
- D. 管理银行账户

**答案:B**

解析:Pages 把仓库变成网站。

## 第 3 题

要分辨一次运行成功还是失败,应去哪里看?

- A. 仓库的 Actions 标签页
- B. 电脑的回收站
- C. 浏览器的收藏夹
- D. 系统通知栏

**答案:A**

解析:在 Actions 标签页可看到运行结果。
