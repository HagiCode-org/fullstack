# 复习测验:安装 GitHub Desktop 并登录

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Install GitHub Desktop and sign in(`install-github-desktop`)
- 题型:单选

## 第 1 题

GitHub Desktop 能在哪些系统上运行?

- A. Linux 的所有发行版
- B. Windows 7 的 32 位版本
- C. macOS 12.0 或更高版本,以及 64 位的 Windows 10 或更高版本
- D. Android 手机

**答案:C**

解析:官方列出的支持系统是 macOS 12.0 或更高版本,以及 64 位的 Windows 10 或更高版本,Linux 暂不支持。
依据:Before you install

## 第 2 题

在 GitHub Desktop 中登录时,用户名和密码应当在哪里输入?

- A. 直接在 GitHub Desktop 的登录框里输入用户名和密码
- B. 在应用打开的浏览器中的 GitHub 页面上输入
- C. 发给 AI 助手,由它代为登录
- D. 写进项目的 README 文件里

**答案:B**

解析:官方说明通过浏览器登录,不支持在应用里直接输入用户名和密码,以保护账号安全。
依据:Sign in to GitHub

## 第 3 题

如果提交时使用的邮箱与当前登录的 GitHub 账号不匹配,GitHub Desktop 会怎样?

- A. 提交前给出警告
- B. 自动删除这次提交
- C. 把提交直接推送到别人的仓库
- D. 什么都不提示,也不会有任何影响

**答案:A**

解析:官方说明,如果 Git 配置里的邮箱不在当前账号中,应用会在提交前显示警告。
依据:Set your commit name and email
