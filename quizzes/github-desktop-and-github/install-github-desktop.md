# 复习测验:安装 GitHub Desktop 并登录

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Install GitHub Desktop and sign in(`install-github-desktop`)
- 题型:单选

## 第 1 题

GitHub Desktop 是什么?

- A. 一个收费的浏览器
- B. GitHub 出品的免费应用,可以用点击完成 Git 操作,无需终端
- C. 一个文字游戏
- D. 一个操作系统

**答案:B**

解析:它让你不用终端就能完成课程里的所有操作。

## 第 2 题

应该从哪里下载 GitHub Desktop?

- A. 任意网盘
- B. 陌生人发来的文件
- C. GitHub 官方网站
- D. 聊天群里的链接

**答案:C**

解析:自检标准强调要从官方站点下载。

## 第 3 题

登录成功后,GitHub Desktop 会显示什么?

- A. 你的银行卡号
- B. 你的身份证号
- C. 什么都不显示
- D. 你的用户名

**答案:D**

解析:能看到用户名说明登录成功。
