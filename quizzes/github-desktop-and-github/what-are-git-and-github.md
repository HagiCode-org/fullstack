# 复习测验:什么是 Git 和 GitHub

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:What are Git and GitHub(`what-are-git-and-github`)
- 题型:单选

## 第 1 题

Git 与 GitHub 的关系是什么?

- A. 两者完全是同一个东西
- B. Git 是记录和管理改动的工具,GitHub 是存放并共享这些项目的网站服务
- C. Git 是网站,GitHub 是编辑器
- D. GitHub 是 Git 的杀毒软件

**答案:B**

解析:Git 管版本,GitHub 托管并协作。

## 第 2 题

为什么和 AI 协作时尤其需要版本管理?

- A. 因为 AI 不会写文件
- B. 因为 AI 只能读文件
- C. AI 改文件很快,有时改得不对,需要能退回
- D. 因为这样网速更快

**答案:C**

解析:版本管理让你可以安全试改并随时退回。

## 第 3 题

下列哪一项是对 GitHub 账号推荐的安全措施?

- A. 把密码发给朋友
- B. 使用最简单的密码
- C. 不设置任何保护
- D. 开启额外的登录保护

**答案:D**

解析:自检标准要求账号开启额外登录保护。
