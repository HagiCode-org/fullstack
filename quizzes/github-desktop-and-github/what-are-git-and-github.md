# 复习测验:什么是 Git 和 GitHub

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:What are Git and GitHub(`what-are-git-and-github`)
- 题型:单选

## 第 1 题

Git 与 GitHub 的区别是什么?

- A. Git 是网站,GitHub 是记录文件历史的程序
- B. Git 是记录文件变化历史的版本控制程序,GitHub 是在云端托管这些仓库并提供协作工具的网站
- C. Git 和 GitHub 完全相同,只是名字不同
- D. GitHub 只用于播放视频和保存照片

**答案:B**

解析:Git 负责记录文件每次变化的历史;GitHub 把 Git 仓库放在云端,并增加计划与协作工具。
依据:What Git and GitHub do

## 第 2 题

“提交”(commit)是什么?

- A. 删除一个仓库的操作
- B. 登录 GitHub 时使用的密码
- C. 一个保存下来的检查点,记录一个或多个文件的改动以及一段说明
- D. 一条分支的名字

**答案:C**

解析:提交是带说明的检查点,记录了改动的内容、时间和作者,以便之后回到这里。
依据:Words you will meet

## 第 3 题

开启两步验证后,为什么要妥善保存恢复代码?

- A. 当你无法使用验证器应用时,恢复代码是重新进入账号的方式
- B. 恢复代码可以加快电脑运行速度
- C. 恢复代码可以替代整个代码仓库
- D. 恢复代码会自动公开给所有访客

**答案:A**

解析:官方建议把恢复代码保存在安全的地方,因为丢失验证器时它是找回账号的唯一途径。
依据:Turn on two-factor authentication
