# 复习测验:撤销改动并找回旧内容

- 课程:GitHub Desktop 与 GitHub(`github-desktop-and-github`)
- 课时:Undo a change and restore old work(`undo-and-restore`)
- 题型:单选

## 第 1 题

丢弃尚未提交的改动,会发生什么?

- A. 文件回到上次提交的样子
- B. 文件被永久加密
- C. 仓库被删除
- D. 什么都不发生

**答案:A**

解析:丢弃改动会让文件回到上次提交的状态。

## 第 2 题

为什么经常提交会让撤销更容易?

- A. 提交越多电脑越快
- B. 提交会自动修复错误
- C. 提交会删除旧文件
- D. 每个存档点都可以作为退回的位置

**答案:D**

解析:存档点越密,可退回的位置越多。

## 第 3 题

撤销(revert)一个提交之后应该做什么?

- A. 立即关机
- B. 删除 GitHub 账号
- C. 检查结果是否符合预期
- D. 什么都不做

**答案:C**

解析:自检标准要求撤销后检查结果。
