# 复习测验:发起 Pull Request 并查看改动

- 课程:GitHub 协作:分支与 Pull Request(`github-collaboration`)
- 课时:Open a pull request and read the changes(`open-a-pull-request`)
- 题型:单选

## 第 1 题

Pull Request 是什么?

- A. 请求把分支上的工作合并进 main,并展示具体改动供审阅
- B. 一个删除仓库的按钮
- C. 一个下载按钮
- D. 一种备份格式

**答案:A**

解析:PR 让你在合并前有一个集中审阅的地方。

## 第 2 题

合并之前你应该做什么?

- A. 直接点合并,不必看
- B. 只看第一行
- C. 请别人代看
- D. 阅读全部改动

**答案:D**

解析:自检标准要求合并前读完所有改动。

## 第 3 题

合并之后,哪里会有你的工作?

- A. 只在分支上
- B. 只在回收站
- C. GitHub 和你电脑上的 main
- D. 哪里都没有

**答案:C**

解析:合并完成后 main 里包含你的工作。
