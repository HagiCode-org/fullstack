# 复习测验:Issue、Fork 与开源

- 课程:GitHub 协作:分支与 Pull Request(`github-collaboration`)
- 课时:Issues, forks and open source(`issues-forks-and-open-source`)
- 题型:单选

## 第 1 题

Issue(议题)用来做什么?

- A. 记录缺陷、改进想法或请求,并供人讨论
- B. 保存电脑上的文件
- C. 替代 Git 的提交
- D. 用于登录账号

**答案:A**

解析:Issue 是一份带标题和说明的文字记录,任何有读取权限的人都可以在开启 Issue 的仓库中创建它。
依据:What an issue is

## 第 2 题

想改进别人的公开项目,但没有写入权限,应该怎么做?

- A. 直接推送到他们的仓库
- B. Fork 一份到自己的账号,在副本上改动,然后从副本发起 Pull Request
- C. 复制代码但不注明来源
- D. 删除原仓库

**答案:B**

解析:Fork 是你自己的副本,在副本上的改动可以通过 Pull Request 提议合并回原项目,由原项目的维护者决定。
依据:Fork a project

## 第 3 题

一个项目没有 LICENSE 文件时,按默认版权法,别人可以怎样使用它的代码?

- A. 可以随意复制和发布
- B. 只能在 GitHub 上看,不能做任何事
- C. 默认版权法适用,未经许可不能复制、分发或制作衍生作品
- D. 可以删除作者的署名后当作自己的作品

**答案:C**

解析:官方说明,没有 license 时作者保留全部权利,未经许可不能复制、分发或制作衍生作品。
依据:Read the license
