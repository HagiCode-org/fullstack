# 复习测验:在分支上工作

- 课程:GitHub 协作:分支与 Pull Request(`github-collaboration`)
- 课时:Work on a branch(`work-on-a-branch`)
- 题型:单选

## 第 1 题

主线 `main` 应当保持什么样?

- A. 随便改乱也行
- B. 每天删除重建
- C. 始终是能正常工作的版本
- D. 只放草稿

**答案:C**

解析:主线要始终保持可用。

## 第 2 题

为什么在分支上做改动?

- A. 这样能让电脑更快
- B. 不影响 main,试错失败也不会弄坏主线
- C. 这样能少写代码
- D. 这样不需要提交

**答案:B**

解析:分支是独立的一条工作线。

## 第 3 题

分支名应该怎么起?

- A. 清楚、能说明用途
- B. 随机字符
- C. 空格和符号堆在一起
- D. 和 main 一样

**答案:A**

解析:自检标准要求有清楚的分支名。
