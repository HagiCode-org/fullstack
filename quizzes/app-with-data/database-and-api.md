# 复习测验:数据库与 API

- 课程:带数据库的应用(`app-with-data`)
- 课时:The database and the API(`database-and-api`)
- 题型:单选

## 第 1 题

刷新页面后条目仍然在,主要原因是什么?

- A. 条目只保存在浏览器的内存里
- B. 条目保存在数据库里,页面会重新向后端请求列表
- C. 页面每次都要手工重新输入条目
- D. 条目保存在一张截图里

**答案:B**

解析:数据库保存条目,后端从数据库读出它们并返回给页面。页面只是数据的展示。

依据:Why an entry is still there after a reload

## 第 2 题

在本课中,API 指的是什么?

- A. 一种数据库表
- B. 一个端口号
- C. 一个浏览器按钮
- D. 一组地址和规则,让一个程序向另一个程序请求数据或要求它做事

**答案:D**

解析:MDN 把 API 描述为应用与其他软件之间的约定。课文用餐厅菜单来比喻它。

依据:What an API is

## 第 3 题

为什么不应该随意把数据库端口发布到你的电脑或网络上?

- A. 因为端口会让页面的字体变小
- B. 因为这样会让页面变慢
- C. 因为已发布的端口不仅对 Docker 主机可见,也可能对外部世界可见
- D. 因为数据库会自动删除条目

**答案:C**

解析:Docker 的端口发布文档说明,发布容器端口在默认情况下是不安全的,所以数据库端口只应留在 Compose 网络内部。

依据:Do not publish the database port
