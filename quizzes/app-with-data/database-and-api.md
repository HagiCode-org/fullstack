# 复习测验:数据库与 API

- 课程:带数据库的应用(`app-with-data`)
- 课时:The database and the API(`database-and-api`)
- 题型:单选

## 第 1 题

数据库在应用里主要负责什么?

- A. 把数据按组织好的表格保存下来,其他部分关掉后仍然保留
- B. 把页面发给浏览器
- C. 给按钮上色
- D. 连接 Wi-Fi

**答案:A**

解析:数据库负责持久保存数据。

## 第 2 题

API 是什么?

- A. 一种新的编程语言
- B. 一个下载按钮
- C. 一种备份格式
- D. 前端和后端约定好的“对话方式”

**答案:D**

解析:例如前端请求“所有留言”,后端返回一个列表。

## 第 3 题

为什么刷新页面后,你添加的条目仍然在?

- A. 因为浏览器记住了你的心情
- B. 因为刷新没有任何作用
- C. 因为数据保存在数据库里,页面刷新后重新从后端取回
- D. 因为条目被印在屏幕上

**答案:C**

解析:刷新只是重新取数据,数据本身存在数据库里。
