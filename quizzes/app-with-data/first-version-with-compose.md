# 复习测验:用 Docker Compose 运行第一个版本

- 课程:带数据库的应用(`app-with-data`)
- 课时:Get the first version running with Docker Compose(`first-version-with-compose`)
- 题型:单选

## 第 1 题

用什么工具运行第一版?

- A. 记事本
- B. 计算器
- C. 画图工具
- D. Docker Compose

**答案:D**

解析:课程用 Docker Compose 一次启动多个容器。

## 第 2 题

怎样验证数据真的保存了?

- A. 停止再启动应用后,添加的条目仍在
- B. 看应用图标
- C. 看终端的颜色
- D. 重装浏览器

**答案:A**

解析:自检标准:停止并重新启动后条目仍在。

## 第 3 题

第一版成功后应该做什么?

- A. 什么都不做
- B. 保存一个存档点
- C. 删除仓库
- D. 立刻改动所有东西

**答案:B**

解析:自检标准:保存了可用版本的存档点。
