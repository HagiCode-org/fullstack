# 复习测验:保护并备份你的数据

- 课程:带数据库的应用(`app-with-data`)
- 课时:Protect and back up your data(`protect-and-back-up-your-data`)
- 题型:单选

## 第 1 题

含有密钥的设置文件应该怎样?

- A. 不要出现在要保存到 GitHub 的改动里
- B. 提交到公开仓库
- C. 发给朋友
- D. 写进网页

**答案:A**

解析:自检标准:密钥所在的设置文件不在保存到 GitHub 的改动中。

## 第 2 题

为什么要做备份并恢复一次?

- A. 为了让应用变快
- B. 为了清空数据库
- C. 为了换设计
- D. 确认备份真的能把数据找回来

**答案:D**

解析:自检标准:做过备份并从中恢复过一个条目。

## 第 3 题

哪类命令你要“每次都先读再运行”?

- A. 显示时间的命令
- B. 显示版本的命令
- C. 会悄悄删除数据的命令
- D. 打开记事本的命令

**答案:C**

解析:自检标准:能说出每次先读再运行的命令。
