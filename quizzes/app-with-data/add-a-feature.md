# 复习测验:添加一个功能

- 课程:带数据库的应用(`app-with-data`)
- 课时:Add a feature(`add-a-feature`)
- 题型:单选

## 第 1 题

课程选择的新功能有什么特点?

- A. 会改变应用存储的内容,例如给书签加标签
- B. 只改颜色
- C. 只改标题
- D. 只改图标

**答案:A**

解析:功能会改变应用存的数据。

## 第 2 题

改动之后,已有的条目应该怎样?

- A. 全部消失
- B. 全部变成新格式并出错
- C. 被自动备份到别处
- D. 仍然正常显示

**答案:D**

解析:自检标准:改动前已有的条目仍能显示。

## 第 3 题

存档点应该在什么时候保存?

- A. 只在改动之前
- B. 只在改动之后
- C. 改动之前和之后
- D. 不用保存

**答案:C**

解析:自检标准:改动前后各保存一次存档点。
