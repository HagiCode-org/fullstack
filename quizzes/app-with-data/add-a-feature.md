# 复习测验:添加一个功能

- 课程:带数据库的应用(`app-with-data`)
- 课时:Add a feature(`add-a-feature`)
- 题型:单选

## 第 1 题

数据表中的一列(column)有数据类型,它的作用是什么?

- A. 决定页面按钮的位置
- B. 决定浏览器缓存的大小
- C. 限制这一列能保存的值的种类
- D. 决定端口号

**答案:C**

解析:PostgreSQL 手册说明,每一列都有数据类型,用来限制可以存入的值。

依据:What a change to storage means

## 第 2 题

在做新功能之前,课文要求你先做什么?

- A. 删除所有条目
- B. 让 AI 直接删除数据库
- C. 关闭 Docker
- D. 先保存一个存档点,以便能回到改动之前

**答案:D**

解析:步骤 2 要求改动前先保存存档点。出了问题时,你可以回到这个状态。

依据:What you will do

## 第 3 题

为什么要检查改动之前保存的旧条目?

- A. 因为旧条目一定会消失
- B. 因为新功能正常工作,并不代表旧数据仍然完好
- C. 因为旧条目不能被新列显示
- D. 因为旧条目只能用截图检查

**答案:B**

解析:只测试新功能可能会漏掉旧数据的损坏。所以课文要求同时打开一条旧条目来确认。

依据:Why you check the old entries
