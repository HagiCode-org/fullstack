# 复习测验:前端和后端

- 课程:带数据库的应用(`app-with-data`)
- 课时:Front end and back end(`front-end-and-back-end`)
- 题型:单选

## 第 1 题

在浏览器里看到的表单和保存按钮,属于应用的哪一部分?

- A. 前端
- B. 后端
- C. 数据库
- D. 端口

**答案:A**

解析:前端是在浏览器中运行的部分,负责显示页面、按钮和表单。

依据:The front end

## 第 2 题

端口(port)的作用是什么?

- A. 决定页面使用的字体
- B. 给电脑增加一块存储空间
- C. 标明程序在哪一扇“门”上接收连接
- D. 保存用户添加的条目

**答案:C**

解析:端口是一个编号,程序通过它接收连接。Docker 的例子 -p 8080:80 就是把电脑上的一扇门连到容器里的另一扇门。

依据:A port is a numbered door

## 第 3 题

保存一条新条目时,正确的顺序是什么?

- A. 数据库先显示结果,然后浏览器发送请求
- B. 浏览器直接写入数据库,不需要后端
- C. 后端只负责显示页面,不接收请求
- D. 前端构造请求,浏览器把它发给后端,后端保存并回复,前端显示结果

**答案:D**

解析:课文描述了四个步骤:构造请求、发送、保存并回复、显示结果。出错时,通常是其中某一步失败。

依据:How the parts talk to each other
