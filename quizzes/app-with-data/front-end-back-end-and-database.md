# 复习测验:前端、后端和数据库

- 课程:带数据库的应用(`app-with-data`)
- 课时:Front end, back end and database(`front-end-back-end-and-database`)
- 题型:单选

## 第 1 题

前端指什么?

- A. 在幕后运行的程序
- B. 保存数据的表格
- C. 电脑的电源
- D. 你在浏览器里看到并点击的部分

**答案:D**

解析:前端是页面、表单和按钮。

## 第 2 题

“只有所有者才能删除条目”这类规则放在哪里?

- A. 后端
- B. 前端的颜色里
- C. 浏览器的书签里
- D. 显示器里

**答案:A**

解析:后端负责决定做什么、执行这类规则。

## 第 3 题

端口(port)是什么?

- A. 电脑上的一个插孔
- B. 电脑上带编号的入口,浏览器用编号找到对应的程序
- C. 一个文件夹
- D. 一种数据库

**答案:B**

解析:前后端各自监听一个端口。
