# 复习测验:让第一版跑起来

- 课程:与 AI 搭档开发(`build-with-ai`)
- 课时:Get the first version running(`get-the-first-version`)
- 题型:单选

## 第 1 题

对第一版应有怎样的预期?

- A. 它必须完美
- B. 它一定是错的所以不用看
- C. 它不需要运行
- D. 它不会完美,这很正常

**答案:D**

解析:课程明确说第一版不完美没关系。

## 第 2 题

得到第一版后,先做什么?

- A. 打开检查,写下哪里不对或缺什么
- B. 立刻修改全部问题
- C. 直接发布
- D. 删除重做

**答案:A**

解析:先记录问题,先不要急着修。

## 第 3 题

为什么此时先不修东西?

- A. 因为修东西很贵
- B. 先把问题看全,再有计划地一个个处理
- C. 因为助手不会修
- D. 因为修了就会丢文件

**答案:B**

解析:课程专门讲了“为什么现在不修任何东西”。
