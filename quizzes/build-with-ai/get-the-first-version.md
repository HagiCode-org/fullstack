# 复习测验:让第一版跑起来

- 课程:与 AI 搭档开发(`build-with-ai`)
- 课时:Get the first version running(`get-the-first-version`)
- 题型:单选

## 第 1 题

第一版网站做出来之后,课文建议你先做什么?

- A. 立刻修复所有问题
- B. 在浏览器里打开网站,逐页检查,并写下问题清单
- C. 删除整个文件夹
- D. 直接发布到公网

**答案:B**

解析:先把网站跑起来、逐页检查并写下缺口,修复要留到后面的课程里一次只改一件事。

依据:What you will do

## 第 2 题

为什么这一课先不急着修复问题?

- A. 修复会让网站变慢
- B. 修复需要付费
- C. 一次改动太多,就难以判断哪一处改动有效或造成了问题
- D. 助手不允许修改第一版

**答案:C**

解析:同时修改很多处,会让你无法分辨哪一次改动解决了问题,哪一次又引入了新问题。

依据:Why you do not fix anything yet

## 第 3 题

关于 Claude Code 等助手的检查点(checkpoint),课文提醒了什么?

- A. 检查点可以完全替代版本控制
- B. 检查点不能替代版本控制,你仍然应该自己保存工作
- C. 检查点会自动把网站发布出去
- D. 检查点只保存图片

**答案:B**

解析:Anthropic 的文档说明检查点不能替代版本控制,所以课文要求你自己用提交保存工作。

依据:Why you do not fix anything yet
