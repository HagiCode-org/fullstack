# 复习测验:小组协作

- 课程:毕业项目：做出并上线你自己的应用(`capstone-project`)
- 课时:Work on a project with others(`team-collaboration`)
- 题型:单选

## 第 1 题

请求组员评审一个拉取请求时,需要对仓库有什么权限?

- A. 只需要阅读权限
- B. 不需要任何权限
- C. 只需要组织的管理员权限
- D. 需要对仓库有写入权限

**答案:D**

解析:GitHub 的请求评审指南说,要请求评审,需要对仓库有写入权限,被请求的人会收到通知。

依据:Share the code through branches

## 第 2 题

评审时选择“Approve”(批准)表示什么?

- A. 改动还没有完成
- B. 改动已经准备好可以合并
- C. 要求作者删除全部代码
- D. 只是留下一条普通评论

**答案:B**

解析:GitHub 的评审指南说,批准表示改动已经准备好可以合并;只留普通评论则不表示批准,也不要求修改。

依据:Review a teammate's change

## 第 3 题

遇到简单的行冲突时,GitHub 的指南怎样说?

- A. 通常可以直接在 GitHub 上解决
- B. 必须删除整个仓库
- C. 永远不能合并
- D. 只能重新下载项目才能解决

**答案:A**

解析:GitHub 的合并冲突指南说,简单的行冲突通常可以在 GitHub 上解决,更复杂的冲突要在本地克隆中解决后再推送。

依据:Handle a merge conflict
