# 复习测验:把成果讲给别人

- 课程:毕业项目：做出并上线你自己的应用(`capstone-project`)
- 课时:Show your work(`show-your-work`)
- 题型:单选

## 第 1 题

一份好的 README 应该让读者做到什么?

- A. 不靠你的解释,知道项目做什么、怎么运行
- B. 只看到一个标题
- C. 看到你的密码
- D. 看到整个聊天记录

**答案:A**

解析:GitHub 的 README 指南说,README 要告诉别人项目为什么有用、能做什么,以及怎样使用。

依据:What the README says

## 第 2 题

三分钟演示通常怎样安排?

- A. 从头到尾读完全部代码
- B. 只展示一张截图
- C. 问题约 30 秒,主要流程约 90 秒,下一步约 30 秒
- D. 演示时不打开应用

**答案:C**

解析:课文建议把三分钟分成问题、主要流程和下一步三部分,并且用真实应用演示主要功能。

依据:How to give the demo

## 第 3 题

在个人资料上置顶仓库,主要是为了什么?

- A. 删除旧的仓库
- B. 让别人快速看到你最好的作品
- C. 提高网站的访问速度
- D. 自动生成新的密钥

**答案:B**

解析:GitHub 的置顶指南说,置顶仓库可以让别人快速看到你最好的作品,这正是作品集的用途。

依据:Link it from your portfolio
