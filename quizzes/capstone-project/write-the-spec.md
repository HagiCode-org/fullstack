# 复习测验:写需求说明

- 课程:毕业项目：做出并上线你自己的应用(`capstone-project`)
- 课时:Write the spec(`write-the-spec`)
- 题型:单选

## 第 1 题

需求说明应该保存为什么文件,放在哪里?

- A. 放在电脑桌面,名字随意
- B. 放在别人的仓库里
- C. 在项目根目录新建名为 spec.md 的文件
- D. 写在聊天记录里,不保存

**答案:C**

解析:课文要求在项目根目录新建 spec.md,并把一句话目标写在第一行,之后每次改动都能对照它。

依据:What you will do

## 第 2 题

一份有用的需求说明大约应该有多长?

- A. 大约两屏
- B. 几十页
- C. 一个单词
- D. 没有长度要求

**答案:A**

解析:课文建议需求说明大约两屏。如果更长,通常是在描述完成后的完整产品,而不是第一版。

依据:Keep the spec short

## 第 3 题

下面哪一句可以作为完成清单中的一行?

- A. 应用看起来很漂亮
- B. 应用很好用
- C. 用户会喜欢
- D. 我能在第一屏看到最近三条笔记

**答案:D**

解析:可以测试的句子是“我做某事,看到某结果”,“看起来漂亮”和“很好用”都无法判断真假。

依据:Test every line before you trust it
