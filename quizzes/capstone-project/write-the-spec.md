# 复习测验:写需求说明

- 课程:毕业项目：做出并上线你自己的应用(`capstone-project`)
- 课时:Write the spec(`write-the-spec`)
- 题型:单选

## 第 1 题

需求说明(spec)在需求之上多了什么?

- A. 一个封面
- B. 一份“完成清单”,每条在测试时非真即假
- C. 一张图片
- D. 一个标题

**答案:B**

解析:课程原话。

## 第 2 题

“它做什么”的每一项应该怎样?

- A. 不需要检查
- B. 放在末尾
- C. 在完成清单里有一条对应的检查
- D. 随意

**答案:C**

解析:自检标准:每项都有对应的清单行。

## 第 3 题

写完 spec 后可以怎样改进它?

- A. 不审阅
- B. 删掉
- C. 交给陌生人
- D. 请助手审阅,并修改合理的意见

**答案:D**

解析:自检标准:请助手审阅并改正合理之处。
