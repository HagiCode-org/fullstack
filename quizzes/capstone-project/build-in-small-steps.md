# 复习测验:小步构建

- 课程:毕业项目：做出并上线你自己的应用(`capstone-project`)
- 课时:Build in small steps(`build-in-small-steps`)
- 题型:单选

## 第 1 题

每个改动应该怎样?

- A. 很大,直接在 main 上
- B. 不存档
- C. 很小,在自己的分支上,存档,并通过 Pull Request 审阅
- D. 不审阅

**答案:C**

解析:课程原话。

## 第 2 题

合并每个 Pull Request 之前要做什么?

- A. 直接合并
- B. 读完它的改动
- C. 关闭它
- D. 删除分支

**答案:B**

解析:自检标准:读了每个 PR 的改动再接受。

## 第 3 题

主版本应该怎样?

- A. 始终能运行,即使还没有所有功能
- B. 允许经常坏掉
- C. 不需要运行
- D. 随时删除

**答案:A**

解析:自检标准:主版本始终能运行。
