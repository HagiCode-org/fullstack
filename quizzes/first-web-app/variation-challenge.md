# 复习测验:挑战：做一个不同的小工具

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Challenge: build a different tool(`variation-challenge`)
- 题型:单选

## 第 1 题

挑战课怎么做?

- A. 重复抄一遍上一个应用
- B. 换一个点子,不按步骤说明,独立再做一遍
- C. 只做设计
- D. 只看别人做

**答案:B**

解析:挑战要求不按步骤独立完成。

## 第 2 题

课程总结的循环是什么?

- A. 购买、安装、卸载、重装
- B. 写、删、写、删
- C. 描述、运行、检查、保存
- D. 看、听、说、写

**答案:C**

解析:自检标准:能用自己的话说出“描述、运行、检查、保存”。

## 第 3 题

第二个工具完成的标志是什么?

- A. 它比第一个大
- B. 它用了更多颜色
- C. 它没有清单
- D. 它的清单每一句在发布地址上都成立

**答案:D**

解析:自检标准:清单每一句在发布地址上有效。
