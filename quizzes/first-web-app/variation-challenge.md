# 复习测验:挑战：做一个不同的小工具

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Challenge: build a different tool(`variation-challenge`)
- 题型:单选

## 第 1 题

挑战课为什么要独立完成?

- A. 因为助手不能用了
- B. 为了证明这个方法适用于任何小工具,并且不依赖逐步指令
- C. 为了减少工作量
- D. 为了删除之前的项目

**答案:B**

解析:挑战课的目标是证明同一方法可以用于其他小工具,而不只是课程里的应用。

依据:What you will do

## 第 2 题

每完成一步之后应该做什么?

- A. 等到最后才检查
- B. 运行应用,对照清单检查,通过后提交
- C. 直接发布
- D. 删除旧提交

**答案:B**

解析:课文的步骤要求每一步都运行、检查,并在通过后提交。

依据:What you will do

## 第 3 题

课程总结的循环是哪一组?

- A. 购买、安装、卸载、重装
- B. 写、删、写、删
- C. 描述、运行、检查、保存
- D. 看、听、说、写

**答案:C**

解析:课文最后总结的循环是描述、运行、检查、保存四步。

依据:Check yourself
