# 复习测验:刷新后保留数据

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Keep the data after a refresh(`add-saving-in-the-browser`)
- 题型:单选

## 第 1 题

为什么刷新页面后列表可能被清空?

- A. 因为浏览器坏了
- B. 页面重新从头加载,只存在于页面内存里的数据会丢失
- C. 因为助手睡着了
- D. 因为网速太慢

**答案:B**

解析:重新加载会从头开始加载页面,所以没有保存到浏览器存储中的数据会消失。

依据:Why the list disappears

## 第 2 题

浏览器存储保存的数据是什么形式?

- A. 图片
- B. 只能是数字
- C. 字符串形式的键和值
- D. 视频

**答案:C**

解析:MDN 说明 Web Storage API 存储的是只包含字符串的键值对,所以应用要把列表转换成文字再保存。

依据:How the storage holds your data

## 第 3 题

为什么不能把浏览器存储当作备份?

- A. 因为它太大
- B. 因为它只能存图片
- C. 因为它是免费的
- D. 因为浏览器在需要空间时可能删除这类数据,用户也可以在设置中删除它

**答案:D**

解析:MDN 说明尽力保存的数据可能被浏览器删除,所以不能只依赖它保存重要内容。

依据:Browser storage is not a backup
