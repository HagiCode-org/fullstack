# 复习测验:刷新后保留数据

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Keep the data after a refresh(`add-saving-in-the-browser`)
- 题型:单选

## 第 1 题

为什么刷新页面后列表可能被清空?

- A. 因为浏览器坏了
- B. 因为网络太慢
- C. 因为助手睡着了
- D. 数据只在页面运行时存在,还没有保存到浏览器存储

**答案:D**

解析:没有保存到存储的数据,刷新后就丢了。

## 第 2 题

验证“删除后刷新仍然保持删除”,说明什么?

- A. 保存的数据确实随操作同步更新
- B. 页面更好看了
- C. 网速更快了
- D. 浏览器升级了

**答案:A**

解析:自检标准:删除的条目刷新后仍然是删除状态。

## 第 3 题

第一次打开、什么都没存时,应用应该怎样?

- A. 直接崩溃
- B. 仍然能正常工作
- C. 要求先注册
- D. 自动关闭

**答案:B**

解析:自检标准:没有存储内容时也要正常工作。
