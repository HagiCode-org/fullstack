# 复习测验:写应用需求

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Write the app brief(`write-the-app-brief`)
- 题型:单选

## 第 1 题

应用需求的篇幅有什么要求?

- A. 越长越好
- B. 一个字就够
- C. 一屏之内写得下,并有“暂不做”清单
- D. 不用写

**答案:C**

解析:自检标准:需求在一屏内,并含“暂不做”的清单。

## 第 2 题

完成清单里每一项应该怎样写?

- A. 写成感想
- B. 写成一句“我能……”
- C. 写成颜色名
- D. 不写

**答案:B**

解析:每个功能对应一句“我能……”。

## 第 3 题

需求最后应该保存在哪里?

- A. 你的仓库里
- B. 只在聊天窗口里
- C. 只在脑子里
- D. 发给陌生人

**答案:A**

解析:自检标准:需求保存在仓库中。
