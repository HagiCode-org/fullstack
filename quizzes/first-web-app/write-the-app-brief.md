# 复习测验:写应用需求

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Write the app brief(`write-the-app-brief`)
- 题型:单选

## 第 1 题

完成清单(done checklist)应该怎样写?

- A. 写成一段感想
- B. 写成一组以“我能”开头的句子,全部成立时应用才算完成
- C. 写成颜色名称
- D. 不写,靠感觉判断

**答案:B**

解析:每个功能对应一句“我能……”,清单里的每句话在测试时都要成立。

依据:What you will do

## 第 2 题

为什么要把需求保存为仓库里的文件?

- A. 助手可能不记得之前的聊天内容,文件可以随时找回
- B. 为了减少文件数量
- C. 为了让应用运行得更快
- D. 为了删除历史版本

**答案:A**

解析:聊天内容可能难以找回,保存在仓库中的文件可以随时打开和修改。

依据:Why write it down

## 第 3 题

需求中的示例应该怎样写?

- A. 使用真实的银行卡号
- B. 使用真实的密码
- C. 使用编造的示例数字,例如“一杯咖啡 3.50”
- D. 使用朋友的身份证号

**答案:C**

解析:示例只需要说明想法,不需要真实的个人信息,所以应使用编造的数字。

依据:Keep personal data out
