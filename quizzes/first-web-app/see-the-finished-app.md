# 复习测验:看看完成的应用

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:See the finished app(`see-the-finished-app`)
- 题型:单选

## 第 1 题

“页面”和“应用”的区别是什么?

- A. 两者完全一样
- B. 页面需要数据库,应用不需要
- C. 页面展示信息并保持不变,应用会对你的操作做出反应
- D. 应用只能在手机上用

**答案:C**

解析:应用会随你的输入和点击而变化。

## 第 2 题

“状态(state)”指什么?

- A. 应用的颜色主题
- B. 应用在此刻记住的全部内容
- C. 应用的价格
- D. 应用的作者

**答案:B**

解析:状态变化时,屏幕也随之变化。

## 第 3 题

浏览器存储(browser storage)的数据存在哪里?

- A. 你自己的浏览器里,清除站点数据后会消失
- B. 云端的数据库里
- C. 所有人都能看到的服务器上
- D. 你的手机号里

**答案:A**

解析:数据不会发到服务器,只留在这个浏览器。
