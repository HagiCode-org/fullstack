# 复习测验:得到第一个版本

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Get the first version(`first-version`)
- 题型:单选

## 第 1 题

第一版做好后,应该先对照什么来检查?

- A. 应用的颜色
- B. 完成清单里的每一句
- C. 助手说它做好了
- D. 代码的行数

**答案:B**

解析:完成清单是检查第一版的标准,要逐句确认哪些已经能运行。

依据:What you will do

## 第 2 题

在 GitHub Desktop 里保存一个检查点,使用的操作是什么?

- A. 删除文件夹
- B. 重命名项目
- C. 提交(commit)
- D. 关闭电脑

**答案:C**

解析:提交会记录特定的改动、时间和作者,以后可以回到这个版本。

依据:Why a checkpoint helps

## 第 3 题

助手只给了一条命令,而你用的是 Windows 电脑,应该怎样做?

- A. 直接运行它,不必看系统
- B. 不运行任何命令
- C. 要求助手提供 Windows 版本
- D. 删除项目后重新开始

**答案:C**

解析:课文的步骤要求你按自己的系统取得对应的命令,缺少时就向助手要。

依据:What you will do
