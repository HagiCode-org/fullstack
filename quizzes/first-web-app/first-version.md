# 复习测验:得到第一个版本

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Get the first version(`first-version`)
- 题型:单选

## 第 1 题

第一版做出来后,你应该先确认什么?

- A. 应用有漂亮的图标
- B. 代码行数很多
- C. 它能联网
- D. 应用能启动并在浏览器里打开,能添加和删除条目

**答案:D**

解析:自检标准:能启动、能打开、能增删条目。

## 第 2 题

对照什么来检查第一版?

- A. 你的完成清单
- B. 别人的评论
- C. 助手的自夸
- D. 随机抽查

**答案:A**

解析:用完成清单对照检查。

## 第 3 题

为什么要提交可用的第一版?

- A. 为了让文件变少
- B. 以后出问题可以回到它
- C. 为了删掉历史
- D. 为了让应用变快

**答案:B**

解析:提交的第一版是以后可回退的位置。
