# 复习测验:添加筛选和合计

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Add filters and totals(`add-filters-and-totals`)
- 题型:单选

## 第 1 题

“筛选”功能做什么?

- A. 删除所有条目
- B. 只显示符合你所选条件的条目
- C. 把条目变成图片
- D. 把条目发给别人

**答案:B**

解析:筛选就是缩小显示范围。

## 第 2 题

“合计”功能做什么?

- A. 把文字翻译成英文
- B. 备份数据
- C. 把数字加起来
- D. 排序按钮

**答案:C**

解析:合计把数字相加。

## 第 3 题

怎么验证合计是对的?

- A. 只看助手说对
- B. 看页面颜色
- C. 随便猜
- D. 和你自己的计算对比

**答案:D**

解析:自检标准:合计与你自己算的一致。
