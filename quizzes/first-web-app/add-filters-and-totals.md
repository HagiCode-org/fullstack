# 复习测验:添加筛选和合计

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Add filters and totals(`add-filters-and-totals`)
- 题型:单选

## 第 1 题

在 MDN 的描述中,filter 方法会做什么?

- A. 删除原来的数组
- B. 把每个元素翻译成文字
- C. 对每个元素调用一个函数,并生成由函数结果为真的值组成的新数组
- D. 把数组从小到大排序

**答案:C**

解析:MDN 说明 filter 为每个元素调用一次函数,并返回结果为真的值组成的新数组。

依据:How the code works, in short

## 第 2 题

合计(total)应该怎样检查?

- A. 用计算器自己算三条数据,再与应用比较
- B. 只相信助手的算术
- C. 看页面颜色是否好看
- D. 随便估计一个数

**答案:A**

解析:课文要求你不要相信助手的算术,而是用自己的计算对照检查。

依据:What you will do

## 第 3 题

合计应该跟随筛选结果变化,为什么先做筛选?

- A. 因为筛选比较便宜
- B. 因为合计只应该加总通过筛选的条目,所以筛选先完成
- C. 因为两者没有关系
- D. 因为合计必须在筛选之前

**答案:B**

解析:课文说明合计只应该加总通过筛选的条目,所以两者的先后顺序很重要。

依据:Why the order matters
