# 复习测验:修复一个故意留下的问题

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Fix a planted problem(`fix-a-planted-problem`)
- 题型:单选

## 第 1 题

为什么不能只看助手对改动的总结就判断修复成功?

- A. 总结太长
- B. 助手可能做出看似正确但错误的改动,需要你对照清单检查
- C. 助手不会写总结
- D. 总结必须用英文写

**答案:B**

解析:课文说明助手可能改对一处却弄坏另一处,只有你能对照清单发现。

依据:Why this skill matters

## 第 2 题

三次尝试仍然无效时应该怎么做?

- A. 无限尝试
- B. 删除整个项目
- C. 先阅读重置提交的指南,再回到上一个好的提交
- D. 放弃课程

**答案:C**

解析:课文要求先读重置提交的指南,了解后续改动会怎样处理,然后再回到上一个好的提交。

依据:What you will do

## 第 3 题

描述问题时应该包含哪三部分?

- A. 你的名字、电脑型号和日期
- B. 你做了什么、你期望什么,以及实际发生了什么
- C. 助手的名字、版本号和价格
- D. 颜色、字体和图标

**答案:B**

解析:课文给出的三部分描述,能让助手知道该从哪里查找原因。

依据:How to describe a problem well
