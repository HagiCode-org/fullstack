# 复习测验:修复一个故意留下的问题

- 课程:你的第一个 Web 应用(`first-web-app`)
- 课时:Fix a planted problem(`fix-a-planted-problem`)
- 题型:单选

## 第 1 题

本课练习的最有用的技能是什么?

- A. 背诵命令
- B. 写很长的代码
- C. 发现问题、向助手描述它,并检查修复是否真的有效
- D. 换电脑

**答案:C**

解析:这是课程里“最有用的技能”。

## 第 2 题

三次尝试都不行时该怎么办?

- A. 无限尝试
- B. 回到上一次提交,重新开始
- C. 删掉项目
- D. 放弃课程

**答案:B**

解析:自检标准:回到上一个提交并重来。

## 第 3 题

修复之后你还要确认什么?

- A. 清单中的其他项仍然通过
- B. 页面变成了另一个页面
- C. 文件名没变
- D. 浏览器变快了

**答案:A**

解析:修复不能破坏其他功能。
