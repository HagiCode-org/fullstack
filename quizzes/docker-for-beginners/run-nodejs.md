# 复习测验:运行 Node.js

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Run Node.js(`run-nodejs`)
- 题型:单选

## 第 1 题

`docker run --rm` 的特点是什么?

- A. 容器一直运行,不会结束
- B. 让容器使用更多的内存
- C. 程序结束后自动删除这个容器
- D. 把镜像保存到本机

**答案:C**

解析:`--rm` 让容器在程序结束时自动被删除。

## 第 2 题

为什么能“不在电脑上安装 Node.js”就运行脚本?

- A. 因为脚本会被自动翻译成 Python
- B. 因为官方的 `node` 镜像里已经带有 Node.js,脚本在容器里运行
- C. 因为浏览器自带 Node.js
- D. 因为 Docker 会在电脑上偷偷安装 Node.js

**答案:B**

解析:容器来自官方 `node` 镜像,Node.js 在容器里。

## 第 3 题

想让浏览器访问容器里的 Web 服务,必须做到哪两点?

- A. 程序监听所有网络接口,并且发布端口(如 `-p 3000:3000`)
- B. 只要程序在运行就行
- C. 只要把容器改名为 web
- D. 必须先停止 Docker

**答案:A**

解析:程序要监听所有接口,并用 `-p` 发布端口,浏览器才能连上。
