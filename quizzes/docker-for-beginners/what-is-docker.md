# 复习测验:什么是 Docker？

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:What is Docker?(`what-is-docker`)
- 题型:单选

## 第 1 题

在 Docker 里,镜像和容器的关系是什么?

- A. 镜像是正在运行的程序,容器是它的模板
- B. 镜像是打包好的模板,容器是由它启动的运行中副本
- C. 两者完全相同,只是名字不同
- D. 镜像只能在网络上使用,不能存放在电脑上

**答案:B**

解析:镜像是模板,由它启动的运行中副本才叫容器。

依据:Words you will meet

## 第 2 题

删除一个容器之后,它所用的镜像会怎样?

- A. 镜像也会被一起删除
- B. 镜像会变成一个新的容器
- C. 镜像会被自动发送到网络
- D. 镜像会被保留在电脑上

**答案:D**

解析:删除的只是运行中的副本,作为模板的镜像仍然保留。

依据:Words you will meet

## 第 3 题

为什么数据库适合把数据放在卷(volume)里?

- A. 因为卷能让数据库运行得更快
- B. 因为卷会自动压缩数据
- C. 因为卷在容器被删除后仍保留数据
- D. 因为卷只能用于网页文件

**答案:C**

解析:卷是 Docker 在容器之外保存的存储,容器删除后数据仍在。
