# 复习测验:什么是 Docker？

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:What is Docker?(`what-is-docker`)
- 题型:单选

## 第 1 题

容器(container)指的是什么?

- A. 一台完整的虚拟电脑,自带显示器和键盘
- B. 把程序和它需要的文件、设置装在一起的小型密封包
- C. 只用来存放网页的文件夹
- D. 一种专门写数据库的编程语言

**答案:B**

解析:容器把程序连同所需的文件和设置装在一起,所以便于整体运行。

## 第 2 题

为什么同一个容器可以在不同的电脑上以同样的方式运行?

- A. 因为这些电脑都装了同一个浏览器
- B. 因为容器会自动把程序改写成各系统的版本
- C. 因为程序所需的文件和设置都在容器里,电脑只需要装有 Docker
- D. 因为容器只能在一台电脑上运行

**答案:C**

解析:依赖都打包在容器里,只要有 Docker 就能照样运行。

## 第 3 题

本课程里的“数据库”是用来做什么的?

- A. 把网页发送给浏览器
- B. 把 JavaScript 翻译成英语
- C. 管理电脑的网络连接
- D. 把数据按有组织的表格保存起来

**答案:D**

解析:数据库负责保存有组织的数据;把网页发给浏览器的是 Web 服务器。
