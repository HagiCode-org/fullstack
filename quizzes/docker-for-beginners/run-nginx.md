# 复习测验:运行 Nginx

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Run Nginx(`run-nginx`)
- 题型:单选

## 第 1 题

`-p 8080:80` 的作用是什么?

- A. 让容器每 80 秒重启一次
- B. 把容器的 80 端口连到你电脑的 8080 端口
- C. 把 8080 个文件复制到容器里
- D. 限制容器只能使用 80 MB 内存

**答案:B**

解析:`-p` 把电脑上的端口和容器里的端口连起来,这样浏览器才能访问。

## 第 2 题

想看 Nginx 容器打印了什么(包括每次访问),应该用哪个命令?

- A. `docker rm`
- B. `docker stop`
- C. `docker logs`
- D. `docker run`

**答案:C**

解析:`docker logs` 显示容器输出的内容。

## 第 3 题

想让 Nginx 提供你自己写的页面,课程使用了哪个选项?

- A. `-p`
- B. `--rm`
- C. `-a`
- D. `-v`(把电脑上的文件夹连到容器里的文件夹)

**答案:D**

解析:`-v` 把电脑上的文件夹连接到容器内的文件夹。
