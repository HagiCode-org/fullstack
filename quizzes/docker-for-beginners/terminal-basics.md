# 复习测验:终端第一课

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Your first look at the terminal(`terminal-basics`)
- 题型:单选

## 第 1 题

在 Windows 上,本课程使用哪个终端?

- A. 命令提示符
- B. Windows PowerShell
- C. 浏览器地址栏
- D. 记事本

**答案:B**

解析:本课说明在 Windows 上使用 Windows PowerShell 运行课程中的全部命令。

依据:Open it on Windows

## 第 2 题

复制命令时,哪一种做法是正确的?

- A. 连同盒子的边框一起复制
- B. 把命令改写成自己的说法
- C. 只复制盒子里的命令文本,然后按一次回车
- D. 把行首的 $ 符号也复制进去

**答案:C**

解析:只复制盒子里的命令文本,按一次回车即可运行。

依据:Copy, paste and Enter

## 第 3 题

按下 Ctrl+C 的作用是什么?

- A. 复制选中的文字
- B. 停止终端里正在运行的命令
- C. 删除一个容器
- D. 打开系统设置

**答案:B**

解析:Ctrl+C 停止当前终端窗口里运行的命令,并不会删除容器。

依据:Stop a running command (Ctrl+C)
