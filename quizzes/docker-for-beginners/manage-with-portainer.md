# 复习测验:用 Portainer 管理容器

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Manage containers with Portainer(`manage-with-portainer`)
- 题型:单选

## 第 1 题

Portainer 是什么?

- A. 一个在浏览器里查看和管理容器、网络、卷的网页工具
- B. 一种新的编程语言
- C. 一个数据库
- D. 一个代码编辑器

**答案:A**

解析:Portainer 社区版提供网页界面来管理 Docker。

## 第 2 题

为什么安装 Portainer 时要特别注意安全?

- A. 因为它很占磁盘
- B. 因为它会自动删除所有容器
- C. 因为它不能离线使用
- D. 因为它需要访问 Docker 引擎,应保留在自己电脑上并保护好管理员账号

**答案:D**

解析:能访问 Docker 就能控制容器,所以要保护管理员账号并避免暴露。

## 第 3 题

在 Portainer 里停止或删除一个容器,效果与什么相同?

- A. 只是隐藏了容器
- B. 会让 Docker 退出
- C. 与此前学过的 Docker 命令效果相同
- D. 只影响 Portainer 自己

**答案:C**

解析:界面操作与对应的 Docker 命令效果相同。
