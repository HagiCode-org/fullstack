# 复习测验:安装 Docker

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Install Docker(`install-docker`)
- 题型:单选

## 第 1 题

读这一课时,应该怎么看各系统的安装说明?

- A. Windows、macOS、Linux 三段都照着做一遍
- B. 只看最短的那一节
- C. 任选一节,三种系统的步骤是一样的
- D. 只看自己系统对应的那一节

**答案:D**

解析:课程要求只跟随自己系统对应的小节。

## 第 2 题

如果课程里写的按钮或菜单名称和官方安装页面不一致,应该以谁为准?

- A. 以官方页面为准
- B. 以本课程为准
- C. 以搜索结果里排第一的博客为准
- D. 以朋友的电脑上的界面为准

**答案:A**

解析:官方页面是权威来源,名称变了就照官方页面做。

## 第 3 题

装完 Docker 之后为什么要做“检查是否成功”这一步?

- A. 为了让 Docker 自动更新
- B. 确认 Docker 能正常响应命令,再进入后面的课程
- C. 为了删除安装文件
- D. 为了注册一个 Docker 账号

**答案:B**

解析:先确认安装可用,后面的课才不会因为环境问题卡住。
