# 复习测验:运行 PostgreSQL

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Run PostgreSQL(`run-postgres`)
- 题型:单选

## 第 1 题

把 PostgreSQL 容器删除后,容器自己的文件会怎样?

- A. 全部保留下来
- B. 自动备份到云端
- C. 随容器一起消失
- D. 变成命名卷

**答案:C**

解析:容器自己的文件会随容器删除而消失。

## 第 2 题

想让数据库的数据在容器被删除后仍然保留,应该怎么做?

- A. 把容器改名
- B. 把数据放进命名卷(named volume)
- C. 多开几个容器
- D. 把端口改成 5432

**答案:B**

解析:命名卷在容器删除后仍保留数据。

## 第 3 题

`docker exec` 是用来做什么的?

- A. 在正在运行的容器里执行一条命令
- B. 删除一个容器
- C. 创建一个新的网络
- D. 下载镜像

**答案:A**

解析:`docker exec` 在运行中的容器里执行命令,例如进入 `psql`。
