# 复习测验:更多社区容器

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:More community containers(`more-community-containers`)
- 题型:单选

## 第 1 题

使用会挂载 Docker socket 的工具时应注意什么?

- A. 没有任何风险
- B. 它们能控制你电脑上的 Docker,要谨慎使用并了解风险
- C. 只能在手机上使用
- D. 必须先卸载 Docker

**答案:B**

解析:课程在安全提示里专门说明了 Docker socket 工具的风险。

## 第 2 题

下面哪一项是课程中用卡片介绍的社区容器?

- A. Photoshop
- B. Chrome
- C. Uptime Kuma
- D. Excel

**答案:C**

解析:卡片包括 Dozzle、Uptime Kuma、Adminer 和 Nginx Proxy Manager。

## 第 3 题

试用卡片里的社区容器之后,合理的做法是什么?

- A. 不管它,让它一直运行
- B. 把它们全部公开到互联网
- C. 立即重装 Docker
- D. 按需要清理掉,保持环境整洁

**答案:D**

解析:不再使用的容器和数据应按课程方法清理。
