# 复习测验:Docker 网络

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Docker networks(`docker-networks`)
- 题型:单选

## 第 1 题

怎样才能让容器之间“按名字”互相找到?

- A. 使用默认网络
- B. 创建并使用自定义网络(如 `course-net`)
- C. 发布更多端口
- D. 重启 Docker

**答案:B**

解析:自定义网络提供容器名字解析,默认网络不提供。

## 第 2 题

“发布端口”和“网络”分别解决什么问题?

- A. 两者完全一样
- B. 发布端口让容器连到容器,网络让电脑连到容器
- C. 发布端口让电脑连到容器,网络让容器连到容器
- D. 发布端口只用于数据库

**答案:C**

解析:发布端口连接“你的电脑与容器”,网络连接“容器与容器”。

## 第 3 题

在默认网络上,第二个容器按名字访问数据库会怎样?

- A. 可以访问
- B. 自动创建一个新网络
- C. 数据库会被删除
- D. 访问不到,因为默认网络不提供按名字查找

**答案:D**

解析:课程专门对比了这一点:默认网络没有名字解析。
