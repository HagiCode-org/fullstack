# 复习测验:读懂报错,学会求助

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Read an error and ask for help(`read-errors-and-ask-for-help`)
- 题型:单选

## 第 1 题

终端里出现红色文字,最合理的第一反应是什么?

- A. 立刻重装系统
- B. 关机睡觉
- C. 把电脑砸了
- D. 先读一读,红色不一定代表严重错误

**答案:D**

解析:先读内容,再判断是不是真的出错、错在哪里。

## 第 2 题

向别人或 AI 求助时,应该怎样给出报错?

- A. 原样复制报错文字,不要用自己的话转述
- B. 只说“报错了”
- C. 只说“不行”
- D. 只发一个表情

**答案:A**

解析:原样文字最利于别人定位问题。

## 第 3 题

一条好的求助信息应该包含什么?

- A. 只写你的名字
- B. 你做了什么、期望什么、实际发生了什么、你的系统
- C. 只写“求助”
- D. 只写一个感叹号

**答案:B**

解析:这四项能让别人不用追问就能开始排查。
