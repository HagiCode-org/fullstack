# 复习测验:读懂报错,学会求助

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Read an error and ask for help(`read-errors-and-ask-for-help`)
- 题型:单选

## 第 1 题

读报错时,应先找哪一行?

- A. 第一个空白行
- B. 包含 error、failed 等关键词、指出出错对象的那一行
- C. 最长的路径
- D. 一串很长的标识符

**答案:B**

解析:关键行通常包含 error、failed、denied 等词,并指出出错的名字。

依据:Find the key line

## 第 2 题

为什么求助时要原样复制报错,而不是转述?

- A. 因为转述会改变一个字母,导致搜索或解释无效
- B. 因为复制可以省略命令
- C. 因为报错必须是红色的
- D. 因为复制会删除日志

**答案:A**

解析:一个字母的改变就可能让搜索和解释失效,所以应原样复制。

依据:Copy it exactly, do not retype it

## 第 3 题

一个好的求助请求应包含哪些内容?

- A. 只写“不行了”
- B. 你做了什么、期望什么、实际发生了什么、系统和已尝试的方法
- C. 你的密码
- D. 别人电脑的配置

**答案:B**

解析:五项内容让读者不用追问就能理解问题,密码绝不能写进求助里。

依据:Describe the problem
