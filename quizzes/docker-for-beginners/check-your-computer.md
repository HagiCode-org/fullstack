# 复习测验:你的电脑能装 Docker 吗

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Can your computer run Docker?(`check-your-computer`)
- 题型:单选

## 第 1 题

根据本课,Docker Desktop for Windows 默认使用哪种后端?

- A. Hyper-V 与 WSL 无关
- B. WSL 2
- C. 虚拟机镜像文件
- D. 只支持 Linux 容器的旧模式

**答案:B**

解析:本课写明 Docker Desktop for Windows 默认使用 WSL 2 后端。

依据:Windows

## 第 2 题

在 Mac 上,应该如何选择 Docker Desktop 的下载版本?

- A. 只有一个版本,无需选择
- B. 按显示器大小选择
- C. 按芯片选择 Apple silicon 或 Intel 版
- D. 按是否开启游戏模式选择

**答案:C**

解析:Mac 分为 Apple silicon 与 Intel 芯片两种下载,要按自己的芯片选择。

依据:macOS

## 第 3 题

如果电脑不满足 Docker 的要求,课程建议怎么做?

- A. 换一台满足要求的电脑
- B. 跳过安装,直接继续学习
- C. 改用共享服务器替代
- D. 修改 Docker 的源代码

**答案:A**

解析:课程要求所有练习都在自己的电脑上进行,所以不满足要求时要换电脑。

依据:What to do if your computer does not qualify
