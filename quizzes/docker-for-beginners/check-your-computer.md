# 复习测验:你的电脑能装 Docker 吗

- 课程:Docker 入门(`docker-for-beginners`)
- 课时:Can your computer run Docker?(`check-your-computer`)
- 题型:单选

## 第 1 题

为什么要在安装 Docker 之前先检查电脑?

- A. 因为检查之后 Docker 会运行得更快
- B. 因为不检查就无法下载安装包
- C. 因为检查会自动升级系统
- D. 避免装到一半才发现系统、权限或虚拟化不满足要求

**答案:D**

解析:先确认条件,能省下大量返工。

## 第 2 题

在受管控的“托管电脑”上装不了软件时,合理的做法是什么?

- A. 先确认是否被允许,不允许就换一台允许安装的电脑
- B. 想办法绕过管理员的限制
- C. 放弃整门课程
- D. 换一个更大的显示器

**答案:A**

解析:不要绕过限制,课程的练习都在自己的电脑上进行,所以需要换一台允许安装的电脑。

## 第 3 题

具体的系统和硬件要求应该以什么为准?

- A. 朋友的经验
- B. Docker 官方页面上的当前说明
- C. 很久以前的博客
- D. 课程里随便写的数字

**答案:B**

解析:要求会变化,课程要求以官方页面为准。
