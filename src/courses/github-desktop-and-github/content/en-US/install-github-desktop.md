**GitHub Desktop** is a free app from GitHub that lets you do everything in this course by clicking, with no terminal. In this lesson you will install it and sign in with the account you made in the last lesson. At the end the app will be open, signed in and ready to use.

GitHub Desktop is available for macOS and Windows only. There is no official version for Linux. If you use Linux, read the other lessons and follow the parts that happen on the GitHub website, and ask your AI helper how to do the same steps with the tools you have.

## What you will do

1. Open the official GitHub Desktop download page from GitHub's own website. Do not use a download link from a search advertisement or a third-party site.
2. Download the version for your computer and run the installer. On macOS, drag the app into your Applications folder when asked.
3. Open the app and choose the option to sign in with GitHub. Your browser opens so you can approve the sign-in on the GitHub website.
4. Return to the app. It asks for the name and email address to attach to your checkpoints. Use your GitHub username. If you want to keep your email address private, ask your AI helper how to use the private address that GitHub provides.
5. Look at the main window and find the three things you will use most: the list of repositories, the list of changed files and the history.

**Safety note:** approve a sign-in only if you started it yourself a moment ago.

## Check yourself

- GitHub Desktop opens and shows your username.
- You can find the area that lists your repositories.
- You downloaded it from the official GitHub site.
