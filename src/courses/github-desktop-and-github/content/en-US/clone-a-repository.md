To work on a project you first need a copy of it on your own computer. Making that copy is called [cloning](../../../glossary/#github-desktop-and-github-clone). The copy holds the project's files and their whole history, and it stays linked to the original on GitHub, so later you can send your changes up and bring other people's changes down. In this lesson you will create a practice [repository](../../../glossary/#github-desktop-and-github-repository) on GitHub and clone it with [GitHub Desktop](../../../glossary/#github-desktop-and-github-github-desktop). At the end you will have a project folder on your computer that you can open and change.

## Create a practice repository on GitHub

A practice repository is a project that exists only for practice, so mistakes in it do not matter. Create it on the GitHub website first.

1. Sign in to GitHub in your browser.
2. In the upper-right corner of the page, open the menu that offers new items and click **New repository**. The official steps are in [Creating a new repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository).
3. Under the Owner menu, leave your own account selected.
4. Type a name such as `practice-notes`. The name can use letters, digits, dots, hyphens and underscores.
5. Choose a visibility. Choose **Private** for practice, so only you can see the project.
6. Tick the option to create a README. A README is a document that explains what the project is for.
7. Click **Create repository**.

## Clone it with GitHub Desktop

The quickest way starts on the GitHub website. On the repository's main page, click **Code**, then click **Open with GitHub Desktop**. The app opens and asks where to put the copy.

You can also start inside the app. The steps for each system are below. The menu name is the only difference.

**On Windows:**

1. Click **File**, then click **Clone Repository**.
2. Click the **GitHub** tab. If you are signed in to more than one account, choose the account first.
3. Click `practice-notes` in the list.
4. Next to **Local Path**, click **Choose...** and pick a folder you will remember, such as a `projects` folder in your Documents.
5. Click **Clone**.

**On macOS:**

1. In the menu bar, click **File**, then click **Clone Repository**.
2. Click the **GitHub** tab and select `practice-notes`.
3. Next to **Local Path**, click **Choose...** and pick a folder you will remember, such as a `projects` folder in your Documents.
4. Click **Clone**.

The official reference is [Cloning and forking repositories from GitHub Desktop](https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-and-forking-repositories-from-github-desktop).

## Check the copy on your computer

When the clone finishes, GitHub Desktop shows the repository name at the top left, next to **Current repository**. That is how the app tells you which project you are working on. Two things to check:

1. Open the folder you chose in your file manager. This folder is your [local repository](../../../glossary/#github-desktop-and-github-local-repository), the copy you can work in. You should see a `practice-notes` folder with a file called `README.md` inside. The `README.md` file is the same one GitHub shows on the website.
2. Open the History tab in GitHub Desktop. It lists the commits that already exist in the repository, and each one shows its message.

Ask your AI helper: "Explain what each file in this project folder is for." Give it the list of files. Leave the files alone for now. The next lessons show how to change them and keep a record of each change.

**Safety note:** the copy on your computer and the project on GitHub are two places. Changes you make on your computer do not reach GitHub until you [push](../../../glossary/#github-desktop-and-github-push) them, which you will do in the next lessons.

## Check yourself

- Your practice repository exists on GitHub and in a folder on your computer.
- You can find the README file in your file manager.
- GitHub Desktop shows `practice-notes` as the current repository.
- You can say what cloning means in one sentence.
