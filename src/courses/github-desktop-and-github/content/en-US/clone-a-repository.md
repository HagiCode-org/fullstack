To work on a project you first need a copy of it on your computer. Making that copy is called **cloning**. The copy includes the files and the whole history, and it stays connected to the original on GitHub. In this lesson you will create a practice repository on GitHub and clone it with GitHub Desktop. At the end you will have a project folder on your computer that you can open and change.

## What you will do

1. On the GitHub website, create a new repository for practice. Give it a clear name such as `practice-notes`, choose private, and let GitHub add a short description file, called a README, so the repository is not empty.
2. Open GitHub Desktop and choose the option to clone a repository from the internet. Pick your new repository from the list.
3. Choose a folder on your computer to hold the project. Pick a place you will remember, such as a folder named `projects` in your documents, and avoid folders that your cloud storage syncs, because syncing can interfere with the history.
4. Wait for the clone to finish, then use the app to open the folder in your file manager. You should see the README file.
5. Ask your AI helper: "Explain what is in this project folder." Give it the file list, and notice that there is a hidden folder that stores the history. Do not edit or delete it.

**Safety note:** the history lives in that hidden folder. If you delete it, the folder stops being a repository.

## Check yourself

- Your practice repository exists on GitHub and on your computer.
- You can find the README in your file manager.
- GitHub Desktop shows the repository as the current one.
