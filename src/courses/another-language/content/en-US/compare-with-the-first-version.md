You now have the same job done in two languages, or the same job done by script and by app. This lesson teaches the judgement skill of the course: deciding whether a result is good without reading every line. You compare what the programs do, and you ask the AI to explain the differences.

## What you will do

1. Put the two versions side by side, each with its start instructions.
2. Take your finish checklist and run both versions through it. Mark each item as passed or failed for each version.
3. Compare the behaviour you can see: the same input should give the same result. Pick three inputs, including one unusual input such as an empty value, and try them in both.
4. Ask the AI: "Explain in plain words what is the same and what is different between these two versions, without showing me code."
5. Ask it which version it would trust more for this job, and why. Treat the answer as an opinion to check, not a verdict.
6. Compare the effort. Note how many times you had to ask again and how many errors you handed over to the AI in each language.
7. Write three sentences on what you can judge without reading code, and what you could not judge.

## Check yourself

- Both versions were tested with the same three inputs.
- You can name at least one thing that is the same and one that differs.
- You wrote down what you could and could not judge without reading code.
