When you ask an AI for a program in Python, four words come up again and again. You only need to recognise them, so that you understand the AI when it asks you to install something or tells you that something is missing. This is a one-page card to come back to.

## Words you will meet

**Language.** The set of words and rules a program is written in. Python and JavaScript are two languages. The same job can be written in either.

**Runtime.** The program on your computer that reads a program written in a language and carries it out. To run something written in Python you need the Python runtime installed. Without it, the program cannot start.

**Dependency.** A piece of ready-made code that your program borrows from other people, such as a tool for reading web pages. The AI adds dependencies for you, and each one has to be downloaded before the program can run.

**Virtual environment.** A private folder where one project keeps its own runtime settings and dependencies, so that it does not disturb other projects on your computer. The AI usually creates and uses one for you.

## What you will do

1. Read the four words once.
2. Ask the AI: "Do I have Python installed? If not, explain how to install it on my computer in plain steps." Follow the steps and ask again if anything fails.
3. Ask the AI to explain, in two sentences, why a project needs its own virtual environment.
4. Keep the card nearby. When an error mentions a missing runtime or dependency, you will know what the AI means.

**Safety note.** Dependencies are code written by strangers. Ask the AI to use only well-known ones, and to tell you what each one is for.

## Check yourself

- You can say what a runtime is and why a program needs one.
- You know whether Python is installed on your computer.
- You can say what a dependency is and who writes it.
