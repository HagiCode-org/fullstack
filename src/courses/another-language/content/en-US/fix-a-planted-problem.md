A problem is planted on purpose in a practice copy of a small Python program. You do not read Python, and you do not need to. You practise describing the problem, handing the AI the evidence and checking that the fix is right. This is the same habit as in earlier courses, now in a language you do not know.

## What you will do

1. Get the practice copy from the link on the course page and run it with the steps given there.
2. Use it until something looks wrong. A wrong result, a crash or an error message all count.
3. Write down what you did, what you expected and what happened instead.
4. Copy the full error text. If the program shows nothing, ask the AI how to make it show more detail.
5. Hand over your notes and the error text. Ask the AI to explain the cause in plain words before changing anything, and read its explanation.
6. Let it make the fix and run the exact steps that failed again.
7. Run the rest of the program to check that nothing else broke. Ask the AI what else the fix could affect.
8. If three attempts fail, go back to the starting point of the copy and describe the problem differently.
9. Compare how this felt with fixing a problem in the earlier course. Was the language a barrier?

**Safety note.** If the AI suggests installing another dependency to fix the problem, ask why it is needed and what it does.

## Check yourself

- The step that failed now works and the rest still works.
- You gave the AI the exact error text.
- You can say what the cause was in one sentence, even though you did not read the code.
