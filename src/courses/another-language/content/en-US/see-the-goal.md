So far the AI has chosen the tools for you. In the earlier courses it picked the approach, wrote the files and told you how to run them, and your job was to check what it made. In this course you ask it to do a job again, in **Python**. Python is "an easy to learn, powerful programming language", according to [the official Python tutorial](https://docs.python.org/3/tutorial/index.html). You may never have used it, and that is the point.

You are not here to become a Python programmer in eight lessons. The point is to see that you can direct an AI in a language you cannot read, and to learn how to judge the result without reading every line. You will judge it the same way you judged the earlier apps: by what it does.

## What you will do

You have two options for the job. Pick one.

1. **Rebuild the small app** from *Your First Web App*. You already have its brief from the lesson **Write the app brief**, and its done checklist, which has one "I can" sentence for each thing the app does. This is the option the rest of the course assumes, because you can put the two versions side by side.
2. **Write a small script** that does one chore you really do, such as renaming the photos in a folder. A script is a short program that runs a repeated task for you. The same steps apply, and you change only the job description.

Then work through these steps on paper, before you install anything.

1. Write down your choice: the small app, or one script.
2. Write what the job must do, in plain words, without naming any language. Use three to five sentences such as "The app shows every item I add" or "The script moves each photo into a folder named by its date."
3. Write how you will check that the job is done. For the app, reuse the done checklist. For a script, write three example inputs and the result you expect for each.
4. Decide what you want to learn from the comparison. Good questions are how long the work takes, how much you had to explain, and whether both versions give the same results.
5. Note how you feel about working in a language you do not know. You will compare this with how you feel at the end of the course.

Do not install Python or anything else in this lesson. The next lessons ask you to check your computer, and they ask you to install only what the AI tells you to install, with your agreement.

## Why the description comes first

A good description does not change when the language changes. "Show every expense from this month and the total" is the same job in English, in Python or in any other language. If you write the job before you mention Python, you can later see clearly which parts of the result came from what you asked for and which parts the AI decided on its own.

Keep the description short. If it runs to more than one page, you are probably describing how the program works inside, and the AI can decide that. Your part is what the program must do for you and how you will check it.

## Check yourself

- You can describe the job without naming any language.
- You have a short way to check that the job is done.
- You know which of the two options you chose.
