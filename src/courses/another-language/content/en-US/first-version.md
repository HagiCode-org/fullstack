Now the AI writes the first Python version and you run it. For an app, the AI will probably use a framework, a ready-made set of tools for building web apps, such as FastAPI. For an automation script, it may be a single file with no extra tools. Either result is fine. You do not need to understand the code to run it and to judge whether it does what you asked.

## What you will do

1. Create a new folder for this project and open the AI assistant in it.
2. Paste your brief from the previous lesson.
3. Let the AI create the files. Ask it for a short summary of the files and what each one is for.
4. Ask for the exact steps to run it, including anything that must be installed first. Follow them one at a time.
5. Run the app or script. If it is a script, try it on a copy of your files, not on the originals.
6. Compare what happens with your finish checklist, one item at a time.
7. If something fails, copy the full text of the error to the AI and ask it to fix it. If three attempts do not work, go back to your last checkpoint and describe the problem in other words.
8. Save a checkpoint with a message such as "First Python version".

**Safety note.** If the AI asks to install something with administrator rights, or to run a command you do not understand, stop and ask it to explain why that is needed.

## Check yourself

- The program runs from the steps the AI gave you.
- Most of your finish checklist already passes.
- You saved a checkpoint of the working version.
