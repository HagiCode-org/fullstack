This is the last lesson of the course, and you work on your own. You will make the same job a third time, in a programming language you choose, and judge the result with the same checklist and the same test cases you used before. The AI still writes the code. Your job is to set the brief, check the result and explain what mattered.

## Choose a third language

Choose one language, not two. Two good options are JavaScript with Node.js, or another language you have heard of and can check. For JavaScript, the official Node.js website describes Node.js as ["an asynchronous event-driven JavaScript runtime"](https://nodejs.org/en/about). Like the Python runtime from the second lesson, it is the software that runs your program. If you pick a language, make sure you can find its official download page before you agree to install anything.

## What you will do

1. Copy your Python brief and change only the language line. Keep the rules and the finish checklist exactly as they are, because the job has not changed.
2. Ask the AI which runtime, tools and versions it needs for the language you chose, and where each one is officially downloaded. Check that each download address belongs to the tool's own official site before you open it.
3. Install only what you agreed to, using the steps for your system in the next section.
4. Run the finish checklist, then enter the three test cases from **Compare with the first version**.
5. Make a table with three columns: the earlier app, the Python version and the third version. Write what passes, what differs and roughly how long each version took you to get working.
6. Write one paragraph that answers this question: what mattered more than the language?

## Set up for your system

The steps depend on the language you pick, so ask the AI for the commands for your system. Tell it which operating system you use, and which terminal you use: Command Prompt or PowerShell on Windows, or Terminal on macOS. Commands for these terminals can differ, so say which one you are using.

### Windows

Ask the AI for the Windows commands and run them one at a time in the project folder. After each command, read the output. If a command fails, copy the full error text and use the method from **Fix a planted problem**.

### Mac

Ask the AI for the macOS commands and run them one at a time in the project folder. After each command, read the output. If a command fails, copy the full error text and use the method from **Fix a planted problem**.

## Judge it without reading it

Run the same three test cases, write down the expected result before you test, and mark each case as the same or different from the other two versions. Then write what you could and could not judge. Not reading the code is not a weakness here. It is the skill this course has been building: decide from what the program does, and say clearly what you do not know.

## Mistakes to avoid

- Changing the job when you change the language. If the third version does something different, the comparison tells you nothing.
- Installing a runtime from a site you did not check. Use only the official site for the tool.
- Stopping at "it works". Compare it with the other two versions before you decide anything.

## Check yourself

- The third version passes the same finish checklist, or you know exactly why it does not.
- You compared the results using the same inputs.
- You wrote down what mattered more than the language.
