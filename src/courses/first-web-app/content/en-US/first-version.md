In this lesson your AI assistant builds the first version from your brief. You run it, look at it, and compare it with your done checklist. The first version does not need to be beautiful. It needs to run.

## What you will do

1. Open your project folder with your AI assistant, and give it your brief. Ask it to build only the first version: add an item, show the list, remove an item.
2. Ask it how to start the app on your computer, and for the address to open in the browser. Run the command it gives you, after reading what it does. If a command deletes files or installs something you do not recognise, ask the AI to explain it before you run it.
3. Open the address in your browser and try the app, as in the finished example.
4. Go through your done checklist. Tick each "I can" sentence that works, and note each that does not.
5. If something is broken, copy the exact error text from the screen or from the place where you started the app, and give it to the AI. Say what you expected to happen.
6. When the first version works, save a checkpoint: commit the changes in GitHub Desktop with a message such as "First version works".

If the AI wants to add accounts, payments or any online service, say no for now. That is not in your brief.

## Check yourself

- The app starts and opens in your browser.
- You can add and remove an item.
- You committed the working first version, so you can come back to it.
