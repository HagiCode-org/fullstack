This is Path A, for readers who can reach Cloudflare without trouble. Cloudflare is a company that runs a large network of computers. It can read your repository, build your site and serve it from the computers closest to each visitor. At the end you have a site online with a preview link for every change.

Cloudflare is changing its static hosting products, so the names and buttons may differ from what you read here. Follow Cloudflare's current instructions, and use your AI assistant to read them with you.

## What you will do

1. Create a Cloudflare account. Keep the password in a password manager, and never paste it into a chat with an AI assistant.
2. Ask your AI assistant: "I want to host a static website from my GitHub repository on Cloudflare. Which two values will I be asked for: the build command and the output folder?" Check its answer against your project.
3. Connect your GitHub repository to Cloudflare, and enter the build command and the output folder.
4. Start the first publication and open the address Cloudflare gives you.
5. Push a change on a new branch. Open the preview link that Cloudflare creates for it, and check the change before merging.
6. Find where Cloudflare lists earlier publications, and practise going back to the previous one. Rolling back means serving an older version again.

Some plans have limits or cost money. Read what Cloudflare says about price before you turn on anything that is not free.

## Check yourself

- Your site opens at an address on a Cloudflare domain.
- A change on a branch has its own preview link.
- You went back to an earlier version once, and then forward again.
