Every website you have visited is made of the same few things: a [page](../../../glossary/#first-website-page) that shows content, a [browser](../../../glossary/#first-website-browser) that draws the page on your screen, and [files](../../../glossary/#first-website-file) stored on a computer. In this course you will make a small personal homepage with an AI partner. This lesson shows you what that homepage will contain and explains the three words you need before you start. You do not install anything in this lesson.

## The three words

**Page.** One screen of content, such as a home page or an about page. A website is a set of pages that link to each other, so a visitor can move from one to the next.

**Browser.** The program you use to look at pages, such as the one you may be using to read this lesson. [MDN's guide to how the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works) describes what happens when you use a browser to go to a web page: the browser first finds the address of the server that keeps the website, and then it retrieves the website from there.

**File.** Every page is stored as files in a folder. MDN explains that websites are built primarily from HTML, CSS and JavaScript, and that HTML lives inside text files. A file named `index.html` usually holds the home page of a website. Pictures and style settings are stored as files too. When someone visits a site, the browser asks for these files and shows them.

You do not have to learn how these files are written in this course, because the assistant writes them. You do have to know that they exist, because you will open, save and check them.

## What the finished site contains

- A home page with your name, a short introduction and a picture.
- A projects section with three entries, each with a title and a short description.
- A contact line, such as an email address you are happy to share publicly.
- A layout that stays readable on a narrow phone screen.

These four parts are the "done" list you will test at the end of the course. Each part has its own lesson: you will write the brief, get the first version, add the projects section and check the phone layout.

## What you will do

1. Read the list above and decide who the site is about. It can be you, an invented person or a hobby.
2. Write down three projects you will show. They can be real or invented, but keep them honest if they are real.
3. Create an empty folder named `first-website`, using your computer's file manager: File Explorer on Windows, or Finder on a Mac.
4. Open that folder in your AI assistant.
5. Ask the assistant: `In one paragraph, explain what files a small personal website consists of.` Read the answer. You do not need to understand every word yet.

## Check yourself

- You can explain what a page, a browser and a file are, in your own words.
- You have decided who the site is about and written down three projects.
- You have an empty folder open in your assistant.

Go on to **Write the site brief**, where you turn these decisions into a request the assistant can build from.
