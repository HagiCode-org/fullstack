An AI coding assistant is a program you talk to in plain language. You describe what you want, and it writes the files, runs them and reports back. In this lesson you pick one assistant and make sure it can work on a folder on your computer. By the end you will have an assistant that answers when you ask it to create a file.

This course uses HagiCode as the worked example. Other assistants work the same way, so everything you learn here carries over. If you already use another assistant, keep it and follow along.

## What to look for

- **It can work on your files.** The assistant must be able to create and change files in a folder you choose, not only chat about code.
- **It shows what it did.** You should be able to see which files it changed, so you can check its work.
- **It can run what it builds.** An assistant that can start your site and read the error messages saves you a lot of copying.

## A note on cost

Many assistants and the AI models behind them charge for use, or limit how much you can use for free. You may need to pay for the tool, for the model, or both. Check what your choice costs before you start, and set a usage limit if the service offers one.

## What you will do

1. Choose one assistant, using the list above.
2. Install it and sign in, following that tool's own instructions.
3. Create an empty folder on your computer named `my-first-site`.
4. Open that folder in the assistant.
5. Type this request: `Create a file named hello.txt that contains the words "Hello from my AI partner".`
6. Open the folder yourself and look at the file the assistant created.
7. Ask the assistant to change the words in the file, then look at the file again.

## Check yourself

- The assistant is installed and you are signed in.
- A file named `hello.txt` exists in your `my-first-site` folder, and you saw it yourself.
- You know what using this assistant may cost you.
